## Architecture decision

- Chosen: Keep `CommandSceneComponent` as the page-facing scene facade. A pure `scene-placement.ts` computes the 23-ID subset and count model. `CommandStreamsComponent` owns keyed stream buttons, each tribunal's phase cue and roving focus; `CommandCoreComponent` owns the dial, root trigger and seven-state voice ring; `CommandStatusGroupsComponent` owns four noninteractive count cards; `CommandConnectorsComponent` owns the decorative SVG. The scene facade owns one measurement scheduler. Rework the existing `CommandOverlayComponent` and `CommandOverlayPositioner` to anchor one plate to a stream row, the root button or the full-list row. Keep the page's existing exhaustive `CommandWorkListComponent` and dock.
- Rationale: the design handoff names these component responsibilities; current page and overlay already separate scene display, selection, details and rail. DOM rows eliminate canvas hit testing and duplicated label positioning. Static SVG supplies the reference geometry without a frame loop.
- Rejected: ngxui packages (reviewed peers target Angular 21 while this app is Angular 22); WebGL/canvas orb (retains the canvas path); a per-row connector component or observer (unbounded measurement cost); reusing old radial `layoutScene` as a compatibility shim (wrong geometry and duplicate ownership).
- Effect: replace canvas renderer, sprite cache and radial label layout in place. Preserve product capabilities listed below. No dependency, RPC or storage change. The exhaustive work list is usable if decorative SVG fails or measurement is unavailable.

## Integration architecture

- Data: controller projects work → scene placement/counts → keyed stream rows/core/groups → pure connector geometry. Stream/root activation goes scene → page → `store.select(id)` → overlay `activate(id)`; hover goes stream → overlay preview without changing selection. Rail continues to receive the unfiltered projection. Overlay reservation goes overlay → page signal → scene/streams CSS; geometry goes facade → connectors and overlay.
- State lifetime: placement/counts are computed from projection and selected ID; roving index lives in streams; plate preview/pin and timers live in overlay; one resize observer/frame scheduler and document visibility listener live in the scene facade. No extra matchMedia listener. All listeners, timers and animation frames release on destroy/close.
- Boundaries: projection text is interpolated by Angular, never `[innerHTML]`; no new RPC or external request. Existing service/store boundaries remain.
- Failure/rollback: SVG or measurement failure removes only decoration. DOM rows, root, cards, rail, pending input and dock still work. Reversion is a single task-level change; no compatibility shim remains.
- Observability: pure function specs exercise supplied geometry; component/integration specs exercise signal, ARIA and state transitions. Electron visual review after implementation must inspect dark/light at 1440/1100/900/892/400/340, including actual dock shift on hover, row attachment, scrolling pinned slot and ribbon stacking. No runtime log or telemetry added.
