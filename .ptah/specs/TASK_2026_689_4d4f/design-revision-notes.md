## Verification

Headless Chrome opened the offline prototype from `file:`. At 1440/1100/900/892/400px simulated windows with 24 nodes, measured stage widths were 1052/712/512/504/364px; all had **14 SVG paths**, **10 endpoint dots**, **23 scene rows**, and exactly **10/6/4/4/4 fully visible rows**. The last size uses the 340–679px rule. At 900px hover left `aria-pressed=false` while opening a preview; Enter preserved the row as `document.activeElement`, set `aria-pressed=true`, and Escape returned focus to it. Scrolling reduced the visible connector count to 9, consistent with viewport culling and redraw. At 1440/900/400px, the open plate intersected zero dial or status-card rectangles. Selecting an overflowed node in the 32-node sample kept rail focus and 23 scene rows; the link read `+7 completed · +1 more · View all work`. Listening at input level 1 set voice scale to 1.025. The final pass logged no browser exceptions. Node syntax check passed for the inline script. No Nx, Jest, build, serve, Electron or protected port was used.
