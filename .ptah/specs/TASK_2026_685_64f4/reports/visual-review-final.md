## Checks against known review findings

1. Bubble error / Retry state on a failed history load or an unknown agent. Not reproduced in the running app: no failing history was available and the bubble is not mounted in the chat canvas. From the code: the store sets `history = 'error'` on an RPC failure (`subagent-execution.store.ts` `loadHistory` catch) and passes `not-found` / `unresolved` through. The bubble template (`inline-agent-bubble.component.ts:447-480`) and the lane (`subagent-lane.component.ts:200-220`) both render Retry or a message for those states, so it does not stay on "Loading saved output" in those cases. Two silent paths remain (D5).
2. Gap between label and value in the lane details rows. There is a gap. Measured at 1440 and 760, finished and restored: `Model:` / `Task:` / `Parent:` each have 4px (`ms-1`) between `dt` and `dd`, on the same line. Seen in `finished-lane-details-dark-1440.png` ("Model: claude-opus-5-5").
3. One execution header per agent. Yes: exactly 1 visible `ptah-execution-header` in the lane in the running, finished and restored states, and the lane never shows a bubble header on top of it. (The lane DOM also holds two hidden `Worked` rows from the orchestrator transcript, not visible.)

## Defects

### Serious

- D1. Sub-agent tile says `0 tools` for an agent that used tools. Live and finished tiles show `0 tools` (running: `running-tile-dark-1440.png`; finished and restored tiles still show `Completed 0 tools`), while the lane header for the same agent shows `2 tools` while running and `6 tools` when finished (`running-lane-dark-1440.png`, `finished-lane-dark-1440.png`). The tile counts tools from the node's children, and the sub-agent's tree is now in its own store. File: `libs/frontend/chat/src/lib/components/organisms/execution/subagent-tile.component.ts`.
- D2. Restored lane loses the header facts the live lane shows. Live: `Worked for 29s`, `6 tools · 40.4k tokens`, and the usage row `ctx 39.2k cache read 234.4k cache write 23.0k out 802`. Restored: `Worked`, no tool count, no tokens, usage row `ctx — cache not reported out 1.2k`, tab chip `done` with no duration (`restored-lane-dark-1440.png` against `finished-lane-dark-1440.png`). The restored tree holds only the final text message (`nodes: 1`, one text child); the six Read calls are not restored, in either session checked. Not in the "before" images' scope, so no regression claim, but it is a parity gap for "restored lane renders like the main agent".
- D3. Light theme: the `out N` token in the lane usage row is almost invisible. Computed colour is `oklch(0.9 0.076 70.7 / 0.7)` on a background of lightness 0.978, about 1.2:1 by lightness (an estimate; the oklch value was not converted to a ratio). The `—` beside it is also faint (`oklch(0.72 0.18 55 / 0.7)`). Evidence: `finished-lane-details-light-1440.png`, `restored-lane-details-light-760.png`. Dark theme is also low for this row (muted grey `ctx` / `cache` text and amber `out` read about 2.5-2.8:1 by lightness). Component: `libs/frontend/chat/src/lib/components/molecules/agent-card/subagent-usage-summary.component.ts`. WCAG AA 4.5:1 for 11px text.
