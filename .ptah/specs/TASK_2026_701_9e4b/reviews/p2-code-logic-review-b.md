## Five logic questions

1. **Silent failure:** B2 can write successfully while losing the completion notification; B3 can show Installed at a destination that never received the file (`agent-selection.component.ts:993,980`).
2. **Unexpected user action:** Back during install strands state; changing destination then choosing fallback discards location (`agent-selection.component.ts:909,1151`).
3. **Wrong answer from input data:** Mixed target histories share source/file keys; unreadable kept outcomes lose their explanation (`agent-selection.component.ts:1068`; `outcome-summary.component.ts:225`).
4. **Dependency failure/timeout/malformed response:** Plan failures get a generic retry alert (`pack-install-prompt.component.ts:219`); install failures are delivered through the fragile output lifecycle and expose raw error strings (`:465–482`). Missing per-file outcomes fail closed when a files array exists (`:91–98`), but the legacy success-without-files branch marks all requested files installed (`:92`); verify that compatibility contract before treating it as proof of per-file success. A timeout does not establish whether the server eventually wrote.
5. **Unspecified requirement:** Operation lifetime, destination-aware status and persisted kept-reason semantics need explicit contracts. The current source/file keys and component-owned operation expose these omissions (`community-packs-panel.component.ts:218,264`; `pack-install-prompt.component.ts:460`).
