## Five logic questions

1. How does this fail silently — A directory deletion returns normally while stale descendant rows remain, because the exact-path sink call reports no error for a directory path. `libs/backend/thoth-runtime/src/lib/workspace-index-lifecycle.ts:244-250`.

2. What user action produces unexpected behaviour? Deleting or renaming a source directory can leave its old symbols searchable; starting `ptah mcp-serve` against a closed/migrating DB can delay protocol readiness. `libs/backend/thoth-runtime/src/lib/workspace-index-lifecycle.ts:244-250`; `libs/backend/cli-engine/src/lib/bootstrap/with-engine.ts:399-416`.

3. What input data makes this produce a wrong answer rather than an error? A watcher batch whose delete path is a directory makes the symbol store answer queries using rows for files that no longer exist. A workspace-local SQLite file makes non-source database updates enter the lifecycle. `libs/backend/thoth-runtime/src/lib/workspace-index-lifecycle.ts:223-250`; `libs/backend/workspace-intelligence/src/file-indexing/workspace-default-excludes.ts:16-42`.

4. What happens when a dependency fails, times out, or returns a shape it should not? Full-index and reindex rejections are caught and reported non-fatally; watcher construction failures are also reported while the boot run remains active. Cancellation reaches the full indexer's signal. There is no lifecycle timeout, so a dependency that never settles leaves one full run in flight and collapses subsequent changes into a single owed follow-up. `libs/backend/thoth-runtime/src/lib/workspace-index-lifecycle.ts:170-180`; `libs/backend/thoth-runtime/src/lib/workspace-index-lifecycle.ts:252-256`; `libs/backend/thoth-runtime/src/lib/workspace-index-lifecycle.ts:266-294`.

5. What is missing that the requirements never mentioned? Directory event semantics need an explicit choice (recursive delete API versus a full-run fallback), and watch filtering needs an explicit contract for workspace-local state/SQLite paths rather than relying on the indexer's late unsupported-file classification. `libs/backend/thoth-runtime/src/lib/workspace-index-lifecycle.ts:109-120`; `libs/backend/thoth-runtime/src/lib/workspace-index-lifecycle.ts:244-250`.
