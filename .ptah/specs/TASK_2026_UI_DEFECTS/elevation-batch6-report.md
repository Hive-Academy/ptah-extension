# Elevation Batch 6 — overlays and controls

## Delivered

Legacy and native overlay panels in `@ptah-extension/ui` now use one `surface-3` root (`rounded-xl`, menu padding `p-1.5`, popover padding `p-2`). Item hover uses the `bg-surface-2` token. Provider and model fields use the 32px control recipe: `input-sm` / `select-sm`, `h-8 min-h-8`, `rounded-lg`, `bg-surface-0`, `border-surface-border`, and the same `focus-visible` ring as the panels (`outline` 2px, offset 2px, `oklch(var(--s))`).

`surface-3` already supplies the strong border, inset highlight, and raised shadow, so the old `bg-base-200 border border-base-300 shadow-lg/xl` recipe is not combined with it. Row hover uses `hover:bg-surface-2` rather than the full `.surface-2` class, so a menu row does not gain a second border and shadow inside the panel.

## Behaviour preserved

- CDK dropdown and popover still use `cdkConnectedOverlay`, the existing position inputs, backdrop class, attach/detach, and backdrop-click outputs. Popover still creates the CDK focus trap on attach, destroys it on detach, and closes on Escape.
- Native dropdown and popover still position with Floating UI (`flip` + `shift`), keep the `z-40` backdrop and `z-50` panel, and stay `visibility: hidden` until positioned. Popover still stores the previously focused element, focuses the panel on open, restores focus on close, and closes on Escape. Document-click outside-close is unchanged.
- Autocomplete keyboard navigation, listbox roles, compact option density, and the `z-50` native panel are unchanged.
- Active options stay on the primary selection colour. Disabled native options stay `opacity-50` and do not take the hover fill.
- Search and select controls stay `aria-disabled` (not native `disabled`) where they already were, so focus is not dropped.
