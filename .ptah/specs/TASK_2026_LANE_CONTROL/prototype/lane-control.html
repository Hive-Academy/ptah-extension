What do these capabilities mean?

Steer inserts a message into a running turn. Interrupt + resume discards partial work and restarts. Queue waits for the next turn. Continue uses a warm handle; resume uses a saved CLI session. Permission and network modes are only shown as supported when the adapter enforces them. Limit tracking requires a reliable account-specific reader.
