# Batch 3b cross-side review

**Verdict: REVISE**

1. **Blocking — background notifications stop processing on standalone surfaces.** `libs/frontend/chat/src/lib/components/templates/app-shell.component.html:768` places `<ptah-notification-center>` inside the newly detached `#shellRow` (`:81-84`). Its store is component-provided (`libs/frontend/notification-center/src/lib/notification-center.component.ts:28-33`), and its view-bound effects consume completion pulses and pending prompts and schedule sounds (`notification-center.store.ts:150-172,434-455`). On a settings-first boot it is never constructed; after chat → settings its effects pause with the detached view. A session completing while settings is open therefore produces no timely notification sound or announcement; queued pulses are processed only on return to chat. Keep notification event processing in an eagerly created service outside the retained view, leaving the visual bell in the row, and test a completion or prompt arriving both before first chat and while settings is shown.

2. **Minor — the shell unit test cannot detect this row regression.** `libs/frontend/chat/src/lib/components/templates/app-shell.retained-chrome.spec.ts:95-102,137-143` replaces the real row with a canvas-only template. Its source check only requires the canvas outlet to occur after `#shellRow` (`:197-203`), which also passes if the outlet is later moved outside the row. A real-template child can fail on settings while T9–T11 remain green. Assert structural containment in the real Angular template and add a focused test for a stateful child whose behavior must continue on standalone surfaces.

3. **Minor — test stub omits `OnPush`.** `libs/frontend/chat/src/lib/components/templates/app-shell.retained-chrome.spec.ts:76-82` uses default change detection for `StubCanvasComponent`. A regression masked by default detection can leave T9 green while the real `OrchestraCanvasComponent` (`libs/frontend/canvas/src/lib/orchestra-canvas.component.ts:60-67`) fails under `OnPush`. Set `changeDetection: ChangeDetectionStrategy.OnPush` on the stub.

Other reviewed paths: `AppShellComponent`'s `viewChild` uses optional access and its row `ResizeObserver` is disconnected by effect cleanup when the query becomes empty (`app-shell.component.ts:414-435,590-598`); row-local keyboard handlers cannot fire after removal. The e2e case uses a DOM marker on the real tile plus a nonzero gesture counter, so its identity assertion is meaningful. The focused app-shell Jest run passed: 5 suites, 34 tests. E2e was not run.
