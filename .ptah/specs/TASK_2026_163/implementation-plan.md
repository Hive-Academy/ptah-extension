## 1. Codebase Investigation Summary

### The enforcement architecture (verified)

Premium gating exists in FIVE independent enforcement layers:

1. **RPC middleware** — `libs/backend/vscode-core/src/messaging/rpc-handler.ts`
   - `validateLicense()` (rpc-handler.ts:393) blocks **every** RPC call when no valid cached license (rpc-handler.ts:256-263, 400-447).
   - `PRO_ONLY_METHOD_PREFIXES` (rpc-handler.ts:111-114: `setup-status:`, `setup-wizard:`, `wizard:`) require Pro tier.
   - `PRO_ONLY_METHODS` (rpc-handler.ts:128, currently empty) and `LICENSE_EXEMPT_PREFIXES` (rpc-handler.ts:139-145).
2. **FeatureGateService** — `libs/backend/vscode-core/src/services/feature-gate.service.ts:102` (`isFeatureEnabled`, `isProTier`, `hasValidLicense`, `isTrialActive`, `getTrialDaysRemaining`, `invalidateCache`; `PRO_ONLY_FEATURES` at :58). Registered at `di/register-platform-agnostic.ts:68`, token at `di/tokens.ts:91,226`, exported at `src/index.ts:81`.
3. **Activation gates** — extension boot refuses to start the real app without a license:
   - VS Code: `apps/ptah-extension-vscode/src/activation/bootstrap.ts:80-82` → `handleLicenseBlocking()` in `activation/license-gate.ts:66` (welcome-view lockout, `initialView: 'welcome', isLicensed: false` at license-gate.ts:106).
   - Electron: `apps/ptah-electron/src/activation/post-window.ts:106` (`initialView = cached.valid ? null : 'welcome'`).
   - License reactivity: `libs/backend/vscode-core/src/services/license-reactivity/` — `bringUpPremiumSubsystems`/`tearDownPremiumSubsystems` (premium-subsystems.ts:85,214) start/stop the MCP server + CLI skill/agent sync based on tier; bound via `bindLicenseReactivity` (license-reactivity-binder.ts:58) from `apps/ptah-extension-vscode/src/activation/post-init.ts:38` and `apps/ptah-electron/src/activation/wire-runtime.ts:842`.
4. **MCP tool-call gate** — `libs/backend/vscode-lm-tools/src/lib/code-execution/mcp-stdio/mcp-license-gate.ts:70` (`McpLicenseGate.evaluate` denies `license_required`/`pro_tier_required`), plus per-spawn premium check in `libs/backend/cli-agent-runtime/src/lib/cli-agents/agent-process-manager.service.ts:1351-1356`.
5. **`isPremium` flag plumbing** — the single source of truth `isPremiumTier()` (`libs/backend/vscode-core/src/services/license.service.ts:50`) is threaded through the entire SDK config pipeline; downstream, `isPremium === false` disables MCP wiring, enhanced prompts, plugins, and workspace analysis (details in §2C).

### Frontend gating surfaces (verified)

Trial banners, trial-ended modal, upgrade CTAs, premium-gated setup wizard, pro-gated marketplace, license-blocked welcome view (details in §2D-§2F).
