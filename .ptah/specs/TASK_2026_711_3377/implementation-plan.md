## Risks

- Per-run channel discovery varies by installed version; gate Copilot, Antigravity, OpenCode v2 and Grok profile on a canary probe and keep a typed fallback. A passing `--help` check alone does not prove the model saw the policy.
- Browser URL checks alone do not stop redirects or subresources. Install interception before navigation, fail closed, and revalidate before sensitive reads. Check symlink changes at every request; do not cache a target realpath across requests.
- More complete guidance increases context and cost. A 64 KiB ingestion bound and per-channel accounting keep it finite; compact argv fallback plus final command-length guard handles Windows shims.
- Removing per-run files while a resumed process still reads them can break lanes. File ownership follows a process handle, with cleanup in every terminal path and no shared mutable `AGENTS.md`.
- Chrome `file:` opaque-origin behavior depends on flags and browser version; keep `--allow-file-access-from-files` absent and verify with a real local page plus an out-of-root link.
