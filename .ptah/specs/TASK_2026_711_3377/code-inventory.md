## 2. Shared prompt and project guidance

`buildTaskPrompt(options: CliCommandOptions & {resumeRestoresContext?: boolean; resumeDeliveredPreambles?: ResumeDeliveredPreambles}, cli?: CliType): string` is defined at `cli-adapter.utils.ts:540-554`. `CliCommandOptions` includes task, working directory, files, task folder, deliverables, model/binary, MCP port, resume ID, project guidance, effort, approval, agent ID and role (`cli-adapter.interface.ts:43-72`). Order: project guidance; rendered role; `NATIVE_AGENT_TOOL_POLICY`; task; focus files; task folder and generated fallback filename; conditional two-way messaging; final completion contract (`cli-adapter.utils.ts:563-611`). The policy says prefer direct `ptah_*` over `execute_code`, use native CLI write/edit tools because `ptah.files` is read-only, keep tool calls/output small, use only changed-project checks with constrained parallelism, avoid workspace build/serve/e2e, and prefer AST/summary plus targeted reads (`cli-adapter.utils.ts:416-422`).

`TWO_WAY_MESSAGING_GUIDANCE` is emitted only with both agent ID and MCP port (`cli-adapter.utils.ts:445-455,510-512,604-605`). It directs report, caller-message precedence, live agent discovery, and reading `ptah_agent_message`'s returned mode (`cli-adapter.utils.ts:449-455`). Its comment requires no vendor roster, no delivery mode promised as available, and brevity because task-prompt bytes may be argv; it cites 994 bytes and the 8,191 Windows shim cap (`cli-adapter.utils.ts:424-447`).

`getProjectGuidanceContent` reads enabled stored enhanced prompt, extracts from `## Project-Specific Guidance` (or whole prompt if marker absent), excluding preceding core/Ptah system prompts, then caps UTF-8 content to 4,000 bytes with a truncation notice at a heading/newline boundary (`enhanced-prompts.service.ts:75-110,916-945`). The browser-facing API obtains it for the workspace and forwards it to spawn (`ptah-api-builder.service.ts:700-708`; `agent-process-manager.service.ts:688-700`); Ptah CLI separately resolves the same service for its system prompt (`ptah-cli/helpers/ptah-cli-spawn-options.service.ts:181-205,361-372`).
