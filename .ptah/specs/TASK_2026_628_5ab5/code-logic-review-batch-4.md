## Defects

1. **Blocking — queued output is silently lost on destruction.** `D:\projects\ptah-wt-628\libs\frontend\chat-streaming\src\lib\agent-monitor.store.ts:1038-1045`. Scenario: an agent emits its final stdout delta, then the host tears down the store before the next animation frame. `ngOnDestroy` cancels the frame and clears both pending maps; the published agent never receives that output. The test at `agent-monitor.store.spec.ts:2594-2606` codifies this loss. Fix: synchronously apply pending output before cancelling and clearing the queue, then test that the final buffer is present after destruction.
2. **Blocking — hidden-window structured output can grow without bound.** `D:\projects\ptah-wt-628\libs\frontend\chat-streaming\src\lib\agent-monitor.store.ts:1339-1362`; `D:\projects\ptah-wt-628\libs\frontend\chat-streaming\src\lib\agent-output-frame.ts:43-60`. Scenario: a CLI agent repeatedly emits adjacent `text` segments with usage while animation frames are suspended. `appendMergingProse` merges them into one queue segment, so `pending.segments.length` stays at one and the early-flush condition never fires; `pending.usages` gains one entry per delta and the merged content grows indefinitely. `capSegments` is not reached until a frame or unrelated write. Fix: bound queued structured content and usage independently of merged segment count, or flush based on accumulated bytes and report count; preserve all usage totals when folding. Add a suspended-frame test with many adjacent usage-bearing text segments.

## Five failure questions

1. **Silent success-looking failure:** destruction returns normally while losing queued output (defect 1).
2. **User action:** close or replace the webview immediately after output arrives; the last visible output can disappear (defect 1).
3. **Wrong answer from input data:** a long stream of adjacent usage-bearing text segments defeats the queue threshold and can exhaust memory (defect 2).
4. **Dependency failure or delay:** when the frame clock is suspended for a hidden window, raw text remains bounded but structured content and usage do not (`agent-monitor.store.ts:1325-1362`). No separate malformed-dependency result was established by this review.
5. **Missing requirement:** the plan specifies pending raw stdout/stderr bounds (`implementation-plan.md:66-79,843-845`), but does not give a byte or usage bound for coalesced structured segments; the implementation needs one (defect 2).
