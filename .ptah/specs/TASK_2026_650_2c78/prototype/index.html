Setup Wizard generation pages

Static prototype for TASK_2026_650_2c78. Example data only. It uses the app's real anubis (dark) and anubis-light tokens. Every page has a bar at the top (prototype chrome, not part of the design) with a state list, a width list (Fill, 960, 720, 400, 360) and a theme toggle. Narrow widths show the peek bar and the sidebar sheet. The design spec is ../design-spec.md.

Quick flow to click through

  1. Landing: choose Generate agents.
  2. Agents, nothing selected: tick agents or use Select Recommended, then Generate. The preview dialog opens, Confirm Generate shows the running state, the Stop button in the chat stand-in shows the cancelled state.
  3. Narrow: choose width 400 on any page, then open the sheet from the peek bar. Escape closes it.

Opened as file://? State changes use the query string; browsers that block history.replaceState on file:// still re-render, only the address bar does not update.
