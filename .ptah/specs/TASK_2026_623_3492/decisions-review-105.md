## Notes

1. **Silent failure:** a rejected optional chunk deliberately leaves no chip or summaries; the warning at `transcript-turn-summaries.ts:195-202` keeps this observable, and retry is deferred until a meaningful input change. No success-looking result is emitted.
2. **Unexpected user action:** switching/remounting a transcript while its chunk is pending still publishes only the current tab and current inputs by the reactive dataflow above. The current test does not rule out every transient wrong `setSummaries` call, which is the revision item.
3. **Wrong-answer input:** old turns cannot become the result of a later module completion because turn snapshots and slots are read synchronously by `build()` after the namespace signal changes (`transcript-turn-summaries.ts:171-184`).
4. **Dependency failure/shape:** the lazy import rejection clears the shared attempt and is handled by the consumer; malformed resolved module shape is not runtime-validated (`transcript-turn-recap-loader.ts:8-13,49-50`). This is an internal compiled entry rather than an external payload; no evidence here indicates a realistic alternate shape.
5. **Missing requirement:** #104 required coverage of rejection/retry and destroy/remount, but did not explicitly require detecting extra transient wrong-tab writes or verifying root sharing across multiple summary-producing transcripts. Those are necessary to substantiate #105's stronger wording that only the two allowed publications occur.
