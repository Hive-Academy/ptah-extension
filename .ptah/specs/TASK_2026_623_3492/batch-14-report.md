## Design fidelity

Sources used: `design-spec.md` sections 1 and 3 (the sparkline is 30 px tall, the trend pill follows the badge look, the avatar is a 32 px circle) and `prototype/index.html` (`.pill`, `.spark`, `.avatar-d`). Deviations:

- **Sparkline drawing.** The prototype draws the bars as `<i style="--h:…%">`. I used SVG `<rect>` attributes instead, for two reasons. First, the trust specs forbid any `[style]` attribute (`trust-boundary.spec.ts:67`, and the existing stat spec line 23). Second, R4.4 requires the renderer's own chart code. The SVG keeps a natural width of 13 units per point and shrinks with `max-width:100%`.
- **Highlight colour.** The highlight is `primary`, as decision #12 requires. This overrides the design spec's gold.
- **Avatar status dot.** There is none, because `AvatarNode` has no status field.
- **Avatar initials.** They are generated by a rule (first letters of two words, or the first two characters of one word), not hand-picked as in the prototype.
- **Token fallbacks.** Each token use has a theme fallback, for example `var(--dp-hl, oklch(var(--p)))`, so the atoms still render outside a renderer root.

## Risks and edge cases handled

- **Points at the limits.** A series that is all zero, all equal, contains negatives, or contains ±`Number.MAX_VALUE` keeps every bar finite, at least 4 units tall, and inside the 30-unit box. The latest flag is always on the last bar only. The spec pins all of this. The view model already bounds the count to 2..`maxSeriesPoints` (5,000).
- **Trust boundary.** Avatar and trend text go only through `{{ }}` interpolation, never HTML bindings. No URL or image field exists or is rendered, and the hostile-text cases are pinned. No `[style]` attribute appears, so `trust-boundary.spec.ts:67` stays satisfied.
- **Tailwind scanning.** Every tone and bar class is a complete literal string in a map, never concatenated.
- **Initials edge cases.** Surrogate pairs are not split (`Array.from`). A name made only of separators falls back to its own characters. Leading and trailing whitespace is trimmed.
- **Theme.** Both themes inherit the tokens from the renderer root, including the light-theme mix overrides at `surface-renderer.component.ts:111-120`.
- **Avatar in the renderer.** Until Task 15.0 lands, an avatar surface still fails closed with `renderFailed`, by design.
