## Defects and likely locations

1. **Pricing never resolves despite complete token accounting.** The saved `codexUsageCheckpoint` has `coverage: complete`, `cacheSemanticsAmbiguous: false`, `totalTokens: 40,249`, but its thread row has **no `modelId`**. Its pricing state is `knownCost: 0`, `complete: false`, empty provenance; `totalCost` is null. In `libs/backend/agent-sdk/src/lib/codex-app-server/codex-chat-turn-stream.ts`, `calculateExactMessageCost` receives `evidenceModel ?? ''`, so the missing evidence model makes a valid selected model unpriceable. The upstream evidence is formed in `libs/backend/codex-runtime/src/lib/codex-event-translator.ts` only when `data.model` exists. Inspect model identity propagation there and the exact-pricing path; do not infer a different model from the UI. Redacted field evidence: `E\checkpoint-fields.json`.
2. **Session Plan Limits has no resolved account.** The copied DB's `provider_account_profiles`, `provider_account_selections`, `provider_account_run_bindings`, and `provider_account_session_links` tables each had **0** rows, and the tile explicitly reported **Account not resolved**. The native reader's success or failure cannot be determined from this UI result; `provider:getPlanLimits` RPCs succeeded without result values in logs. Suspected binding/display paths: `libs/backend/cli-agent-runtime/src/lib/cli-agents/limits/plan-limit-owner-discovery.service.ts`, `libs/backend/rpc-handlers/src/lib/handlers/provider-rpc.handlers.ts`, and `libs/frontend/core/src/lib/services/plan-limits.store.ts`. Environment-specific account setup may be required. Field evidence: `E\db-metadata-fields.txt`, `E\cost-details.json`, `E\app.log`.
3. **Context and model display drops on history reload.** Tokens persist, but context and model change from **7.8% / GPT 6 Luna** at turn end to blanks after reload and restart. Suspected stats rehydration/display paths: `libs/backend/agent-sdk/src/lib/session-history-reader.service.ts`, `libs/frontend/chat/src/lib/services/chat-store/session-stats-aggregator.service.ts`. Evidence: `E\turn1.json`, `E\reload.json`, `E\app-restart-expanded.json`.
