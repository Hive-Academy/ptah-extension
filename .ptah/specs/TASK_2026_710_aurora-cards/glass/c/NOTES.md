# Ptah Glass (panelist P3): `ptah-glass` + `ptah-glass-light`

Files: `theme.config.js` (paste into `daisyui.themes`), `glass-layer.css` (scoped glass layer, backdrop, fallbacks),
`theme.css` (compiled-equivalent vars, generated by `build-theme-css.cjs`), `index.html` (prototype, open with
`file://`, `?theme=light` preselects light), `shot-*.png` (Playwright renders). `contrast.cjs` and
`backdrop-max.cjs` regenerate the numbers below.

Design idea: the lapis/gold of the Ptah coin. Dark = lapis night with a teal counter-glow top right and a gold
ember bottom right. Light = the same family in daylight: lavender, sky, peach, a trace of gold. Gold is the single
accent in both; the brightest gold is reserved for the one filled action (btn-primary), everything else is glass.

## Contrast (WCAG 2.x, computed)

Method: worst-case backdrop pixel sampled from the rendered page backdrop (brightest pixel `#1e4cb0` for dark, whose
text is light; darkest pixel `#c2affd` for light, whose text is dark), then the translucent fills are alpha-composited
over it in the real stacking order (panel over backdrop, tile over panel, tint over tile). Blur only averages colours,
so the single worst pixel is a conservative bound. Criteria: 4.5:1 body text, 3:1 UI components (WCAG 1.4.3 / 1.4.11).
Light badge tints are 12% in CSS and measured at 14% (stricter). Reproduce: `node backdrop-max.cjs && node contrast.cjs`.

## Blur budget (Electron)

At most 6 blurred surfaces on screen at once, each `blur(18px) saturate(1.45)`: sidebar, navbar, chat panel, right
panel, plus the transient menu/modal at `blur(24px)` (max 2 open). The prototype shell uses exactly 4 static
blurred layers plus overlays. Nothing nested is blurred: tiles, bubbles, tool-call collapses, composer, inputs,
buttons, badges, table rows, menu rows, tooltips (opaque) and the modal scrim (flat dim) are fill + edge only; `bg-base-*` utilities
are fills. The backdrop is a single static `position: fixed` pseudo-element: no animation, no repaint on scroll,
no `background-attachment: fixed`. Opt out for long card lists with `.glass-flat`. `prefers-reduced-transparency`
turns every blur off and makes fills 96-99% opaque; `@supports not (backdrop-filter)` does the same for fills;
`prefers-reduced-motion` zeroes transitions.

   objects from `theme.config.js` as `{ 'ptah-glass': { ... } }` and `{ 'ptah-glass-light': { ... } }` (or
   `...Object.entries(require('./theme.config.js')).map(([k, v]) => ({ [k]: v }))` if the file is moved next to the config).
   If glass becomes the default, change `darkTheme: 'anubis'` to `'ptah-glass'` and `themeRoot: '[data-theme=anubis]'`
   to `'[data-theme=ptah-glass]'` (keeps the bare `:root` fallback off, per the existing comment). Keep anubis
   themes; the 32 stock themes remain in `theme-extra.css`.
2. `libs/frontend/core/src/lib/services/theme.service.ts`:

   - prepend to `DAISYUI_THEMES`: `{ name: 'ptah-glass', label: 'Ptah Glass', isDark: true }, { name: 'ptah-glass-light', label: 'Ptah Glass Light', isDark: false }`
     (`DARK_THEMES` derives from `isDark`, so `data-theme-mode` is set automatically);
   - `EAGER_THEMES = new Set(['ptah-glass', 'ptah-glass-light', 'anubis', 'anubis-light'])` (they are compiled into `styles.css`);

     change it to `ptah-glass`.

   `@layer components { ... }` block placed after the existing semantic-surface block (so it lands after daisyUI and

## Decisions

- **primary = gold (not blue, not teal).** Options: (a) keep anubis mapping, blue primary + gold secondary; (b) gold
  primary; (c) teal primary. Evidence: every btn-primary/link/selection/focus/checked control follows `primary`;
  the references use ONE accent; the lapis backdrop makes a blue primary vanish into it (blue on lapis fails the
  one-accent rule and measures poorly), and teal would drift from the brand. Gold on lapis is the logo (ptah-icon.png)
  and gives 8-10:1 on dark glass. Secondary is a lighter champagne gold so `text-secondary` headings, eyebrows and
  `text-secondary-focus` in existing components stay in the brand family instead of turning blue. Accent = Nile
  teal, used for secondary highlights only. Reversible: swap three hex values per theme.
- **Light primary is a deep gold (#7c5700), the filled button is not.** Text-on-glass needs 4.5:1, so `primary`
  is deep; `.btn-primary` is drawn from `--g-gold-a/b` (same bright gold gradient + dark ink in both themes), so the
  buttons look identical across themes while `text-primary` stays readable.
- **Selected state stays glass.** Nav items, segmented tabs, bubbles: gold-tinted translucent fill + brighter edge,
  never an opaque pill. The only dark solid in light is `btn-neutral` and code blocks (reference 3's dark card).
- **Specificity policy.** Surfaces use `:where()` scope so utilities (`rounded-*`, `bg-*`, `p-*`) still win in the
  real Tailwind order; interactive states use a real prefix to beat DaisyUI's `:hover`/`.active`; `bg-base-*` uses a
  hard prefix because the utility is (0,1,0).
- **Backdrop = `html::before`, `position: fixed`.** Covers the viewport at every scroll position (verified by
  scrolling renders). Alternative `background-attachment: fixed` on html repaints more.
- **No animated aurora.** Animating a full-viewport gradient under 4+ backdrop-filter layers re-runs every blur each
  frame; static is the cheap Electron default. The existing `ptah-aurora-effect` can still be layered locally.
- **Links never turn blue in menus.** `.menu` / `.btn` / `.tabs` / `.navbar` / `.dropdown-content` anchors are forced to
  `color: inherit`, so a global `a { color }` cannot leak into sidebar session names.
- **Tooltips are opaque** (`--g-tooltip`) so the DaisyUI arrow matches and the bubble is readable anywhere; tooltips
  and the modal scrim use no blur.
- **Chat bubbles have no tail**; asymmetric corner radius instead (the DaisyUI tail is a mask and cannot carry a
  border on glass).
- **Icons are inline Lucide-style SVG** (1.5 stroke, `currentColor`) via a `<symbol>` sprite, no glyphs or emoji. The
  prototype uses the real Get ready card and Get Started categories/prompts (Build/Fix/Review/Agents/Explore/Creative)
  from `project-setup-card.component.ts` / `prompt-suggestions.component.ts`; the category icons are the ones that
  component imports (Sparkles, RefreshCw, CheckCircle, Users, ScanSearch, Palette). The decorative hieroglyph footer
  and emoji in the original are intentionally not reproduced.
- **Prototype-only code:** the `--tw-*` transform defaults in `index.html` exist because `full.css` has no Tailwind
  base; the app has them.

## Known limits

- Verified in Chromium (Playwright) only; Electron's Chromium matches. `prefers-reduced-transparency` needs Chromium 118+.
- `glass-layer.css` overrides DaisyUI 4.12 internals (`--btn-color`, menu `:not()` chains); a DaisyUI upgrade needs a
  visual pass.
- Toggles/ranges rely on DaisyUI's internal vars (`--tglbg`, `--range-shdw`) and were checked visually, not exhaustively.
