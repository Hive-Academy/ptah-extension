## Decisions

- **Immutable binding:** use `Pick<ClaudeAccountNamedRoute, provider | routeFingerprint | routeRevision | authEpoch>` and a frozen, non-writable record property. Alternatives were storing the full route or trusting caller association. D17 requires authoritative binding and no directory exposure; storing only identity meets that contract. Reversible through a later deliberate schema change; individual session bindings intentionally cannot be replaced.
- **Installed version:** inject the existing CLI detector optionally and use its executable/version descriptor for named model keys. No guessed version or ambient fallback when it is unavailable. Existing module-loader-only discovery cannot supply version; the detector already owns it. Reversible; no registration change was required because the loader already depends on that token.
- **Epoch validity:** expose `invalidateAccountRoute(route)` on both services for authoritative lifecycle notifications; named reads also observe the supplied admitted epoch. Reject older observed epochs and discard in-flight responses on epoch/query changes. Do not poll credentials or invent an epoch from accountInfo. The integration must supply current admitted routes and invalidation notifications; it is not inferred from mutable credentials. Reversible/additive API.
- **Control-only resource ownership:** named model requests own and dispose temporary queries; quota reads borrow live queries and must not close sessions on timeout. Model cancellation is consumer-refcounted through optional AbortSignal. Alternatives were one subprocess per consumer or closing borrowed quota sessions; existing ownership and plan 211 favor this approach. Reversible.
- **Named cache/settings isolation:** memory-only bounded catalogs (64) and epoch observations (128), separate from ambient persistence/native cache; named control probes load no user/project settings sources. This avoids cached ambient credentials and settings-driven hooks in a metadata probe while A3 remains uncertified. Ambient behavior stays intact. Reversible.
- **Unknown catalog compatibility:** models keep the existing array return contract and use `[]` for unknown; quota route overloads return the explicit closed result union. No fabricated model list or paid inference fallback. Reversible/additive.
