## Decisions

1. **Optional token-only persistence boundary in an owned file.** Options: import concrete auth-providers (cycle), edit forbidden DI/port files, or define the minimal host adapter contract. Evidence: the existing admission port exposes only admit/release/retain, while registry commit/attach and metadata live in separate owners. Chose `libs/backend/agent-sdk/src/lib/helpers/session-lifecycle/session-query-executor.service.ts:559` and `libs/backend/agent-sdk/src/lib/helpers/sdk-query-runner.service.ts:93`. Reversible additive wiring; absence fails closed.
2. **Keep immutable bindings on ordinary resume.** Options: create a new run for the same SDK ID (store collision), mutate old binding (forbidden), or reuse the authoritative binding and idempotent attachment. Evidence: Batch 16's one-to-one SDK/run attachment and immutable saveAccountBound. Chose reuse; forks obtain a new run. Auth epoch can advance only with fresh equality proof; the old persisted binding remains unchanged. Reversible workflow choice; no schema mutation.
3. **Full 64-character identity digest.** Options: reuse the quota display owner key verbatim (provider-prefixed, 16-hex fingerprint), or preserve its trimmed email/organization and domain-tag material with full SHA-256 for the binding schema. Chose full digest because isProviderAccountOwnerKey requires 64 lowercase hex (`libs/shared/src/lib/types/provider-account.types.ts:200`); quota identity material is at `libs/backend/auth-providers/src/lib/quota/provider-owner.resolver.ts:120`. This is a binding-evidence representation, not a change to quota owner keys. Reversible before live certification; future port adapters must use the same material.
4. **Signal-only exits retain.** Options: trust all shim exits, or conservatively retain without numeric status. Evidence: off-thread spawner synthesizes SIGKILL exit after worker error/grace. Chose retention. Reversible when an explicit trustworthy process termination proof becomes available.
5. **No silent named reuse/slash fallback.** Options: let existing active/manager paths ignore selection, implement out-of-scope manager/chat changes, or typed-refuse until Batch 18 carries the binding. Chose refusal. Explicit named selection is a new capability; ambient behavior remains available. Reversible with Batch 18 integration.
