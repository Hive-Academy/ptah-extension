## Conflicts resolved and ideas dropped

1. **Stats presentation:** GLM proposes four compact chips; grok proposes importing the collapsible chat summary with model and context. Use one small local `CommandSessionStatsComponent` for cost, tokens, agents, duration, with context in the header and root plate. The chat summary owns expansion, model rows, and budget surfaces (`chat-ui/.../session-stats-summary.component.ts:171-175,203-241`); importing it makes the stage too wide. Reuse its snapshot-only semantics and formatting helpers. Unknown values remain `—` or the cost badge's unavailable state; `provisional` retains `~` treatment. No derived accounting.
2. **Context threshold:** Use the chat's verified `sessionContextCue` and **70%** warning (`session-stats-summary.component.ts:182-201`), rather than grok's 80%/95% ring tiers. The current shared ring hardcodes 80%/95% (`chat-ui/src/lib/atoms/context-ring.component.ts:32-33`), so add an optional semantic tone input to that component: the default preserves chat behavior, while Command Center passes `normal` or `warning` from its 70% cue. A 95% error color falsely implies an error in this page. The ring and chip use the same known/unknown decision; optional ring only when known.
3. **Elapsed time:** GLM calls `updatedAt` elapsed and applies it to running lanes; grok distinguishes freshness from duration. Use `updatedAt` only for `Updated … ago`. Use verified `startedAt` from a bound lane agent for V15; no arc for unbound lanes. Saturation at five minutes is a visual scale, not an assertion of percent complete.
4. **Link color and contrast:** Keep provider-tinted gradient curves as decorative wayfinding. On light cream, several current `rim` endpoints fall below 3:1 (`scene/command-scene.component.ts:42-48`); do not use them alone for a meaningful direction cue. Draw the chevron in the opaque `idle` state ink. Active links get an opaque state-ink stroke as grok 4 proposes, above the tinted curve, so activity remains legible with motion off. Cache gradient objects by geometry/theme/palette; `setSnapshot` must not rebuild them for voice-only updates.
5. **Ripples and halos:** Keep the root's existing opaque voice ring as the state cue. Faint fading ripples and halo are decorative. Their low-alpha edges are intentionally below 3:1 and must never be the sole status indicator. A reduced-motion frame shows the static ring and state text, with no expansion.
6. **Activity meter:** Recency bars represent age of `lastActivityAt`, not token volume or a score. They stay static, carry an accessible `Updated …` label, and omit when timestamp invalid. Do not animate each card or attach a timer per card.
7. **Dropped:** No duplicate full chat stats component, per-model table, dashboard sparkline, auto narration of figures, canvas text, per-node timer/observer, shadow blur in `draw`, dirty-rectangle engine, WebGL, new layout, or new framework. Existing Canvas/DOM access paths and the 23-node cap (`scene-layout.ts:107`) make those additions unnecessary or harmful.
