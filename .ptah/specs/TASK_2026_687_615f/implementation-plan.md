## Controller split preserve contract

Keep `CommandCenterPageController` as the page-facing Angular provider. Construct plain roster object in controller field initialization with explicit `store`, `tabs`, `chat`, `tribunalTransport`, `DestroyRef`, clock and a lazy voice port (`() => this.voice`); the voice loop's ordinary-question callback reads the roster only when invoked, after construction. No injection of controller into roster and no DI cycle. A single roster instance owns the Tribunal coordinator, active-request/nonce signals, question filtering, invalid Decline state, roster timeout, skipped-pulse grace, pending-input effect (`:412-440`), `store.setPendingInput` and prompt speech. Its public `tribunalRequestActive` signal replaces retained `answerOrdinaryQuestion`'s read of private `activeTribunalRequest` (`:514`). It cancels roster, invalid-Decline and grace timers via `DestroyRef`; also cancels them on relevant state changes.

Preserve as controller facade fields with identical names/return types, delegated to one roster source: `tribunal`, `pendingProposal`, `rosterTimedOut`, `ordinaryQuestion`, `ordinaryChoices`, `permissionRequest`, `shownInput`, `shownProposal`, `undeclinedInvalidQuestionId`; methods `confirmProposal`, `declineProposal`, `timeoutProposal`, `retryInvalidDecline`. Retain in controller: `store`, `tabs`, `coordinator`, `turnAbortable`, `shownSessionStatus`, `canvasUnavailable`, `hoveredNodeId`, `recordWriteFailure`, `latestReply`, `projection`, `voice`; methods `open`, `startVoice`, `muteVoice`, `toggleMuteVoice`, `stopVoice`, `interruptSpeech`, `openVoiceSettings`, `retrySpeech`, `answerOrdinaryQuestion`, `answerPermission`, `sendCommand`, `getLatencyMarks`, `exit`. `sendCommand` delegates Tribunal request lifecycle; `teardownSessionState` delegates roster teardown.

Preserve theme/reduced-motion feeds, projection/selection, status context, marked-tab visibility, voice FIFO, prompt speech, ordinary/permission routing, click-only Confirm and nonce gate, invalid-Decline send gate, workspace teardown, every timer/listener release, fixed-text errors, and existing stale-workspace guard. No public member or behavior is removed.
