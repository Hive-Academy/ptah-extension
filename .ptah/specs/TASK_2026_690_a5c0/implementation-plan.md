## Architecture decision

The session uses one bounded flex height chain and one transcript scroller. The persistent display collection moves into a session-local bottom sheet between the transcript and composer. Every completed `ptah-ui` fence, including `display [id]`, renders in full in its turn; the collection still resolves `display [id]` into the latest surface per ID. The right DISPLAY rail disappears. The inline block or turn chip retains an **Open in display** equivalent: open the sheet and scroll to the corresponding current panel (`context.md:36-44`).

Keep the existing fence parser, resolver and display surface store: they implement turn order, replacement, statuses and view-state retention (`libs/frontend/chat/src/lib/components/organisms/transcript/transcript-display-candidates.ts:13-50`; `libs/frontend/chat-ui/src/lib/organisms/display-panel/display-surfaces.ts:240-263`; `libs/frontend/chat/src/lib/services/display-dock/display-dock.state.ts:224-237,288-325`). **Interactive-state owner:** the sheet alone owns persisted `viewStates` for current ID surfaces. Inline `ptah-ui-block` renders the historical fence snapshot and owns only local renderer interaction; inline edits do not propagate to the sheet or later same-ID fences. Both consume the same compiled fence data where their contracts overlap, but a superseding fence updates only the current sheet surface. The inline action targets the current panel by ID; if eviction or invalidity leaves no current panel, give a local unavailable status instead of opening an unrelated panel.

## Integration architecture

The transcript feed collects display candidates in turn order, including streaming records (`transcript-display-feed.ts:48-102`), and the headless sync compiles and resolves them into per-tab surfaces (`transcript-display-candidates.ts:13-50`, `display-surfaces.ts:240-263`). The Electron sheet reads the current per-ID surfaces and persists its renderer view state by tab (`display-dock.state.ts:37-80,224-237,288-325`); historical inline instances keep local interaction only. Closing a chat tab calls `forgetTab` (`display-dock.state.ts:143-148`); destroying the view releases sheet listeners, pointer capture and any pulse timer. No new RPC or storage format is needed. Canvas and normal Electron chat share the sheet-capable session component. VS Code's null display provider keeps the Agents rail while full inline blocks render without sheet collection (`chat-view.component.ts:235-245,428-437`).
