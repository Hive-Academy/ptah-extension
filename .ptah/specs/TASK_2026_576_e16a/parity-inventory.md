# Parity Inventory - TASK_2026_576_e16a

This inventory covers the Electron git dock in `libs/frontend/git-ui`: the
`GitDockComponent` and everything it hosts. It also covers the surfaces outside
the library that reach git-ui. The dock is mounted lazily from
`libs/frontend/chat/src/lib/components/templates/electron-shell.component.ts:366-382`.

Surfaces outside `git-ui` that are also covered:

- the file-link routing (`libs/frontend/chat/src/lib/services/file-link-router.service.ts`);
- the workspace switch fan-out (`libs/frontend/chat/src/lib/services/workspace-coordinator.service.ts`);
- the Skills clone-diff drawer (`libs/frontend/skill-synthesis-ui/src/lib/components/clones/lazy-diff-view.component.ts`);
- the webview push-handler registration (`apps/ptah-extension-webview/src/app/app.config.ts:62-67, 208-211`).

How to read the table:

- Paths without a prefix are relative to `libs/frontend/git-ui/src/lib/`.
- "New location" names the surface from `task-description.md` (Requirements 4-12).
  File layout is the architect's decision.
- "Test that proves it" names the existing spec that covers the capability
  today. That spec, or its successor on the new surface, must pass before the
  old component is deleted (Requirement 13).

The first version of this list came from a CLI lane (Glm) and was checked
against the source line by line. Corrections are folded in.

## Proposed Removals

These need explicit user approval at Gate 1. Anything not approved becomes
`keep` or `move`.

- **Several file views open at once as tabs** (`git-dock/git-dock.component.ts:127-191`
  for file-view tabs). The spot editor holds one file (Requirement 7.4), and
  the user put a multi-tab editor out of scope. Switching between changed
  files' diffs is not removed: it moves to the canvas tree and list.
- **`SourceControlService.getOriginalContent` (`git:showFile` wrapper)**
  (`services/source-control.service.ts:100-111`). It has no caller in any
  TypeScript file (`current-ptah-surface.md`). The backend `git:showFile` RPC
  is not removed.
- **`GitBranchesService.refreshTags` (`git:tags` wrapper)**
  (`services/git-branches.service.ts:424-430`). It has no call site. The
  backend `git:tags` RPC is not removed.
- **`MonacoLoaderService` and `monaco-theme.ts`**. They are implementation
  detail of the Monaco surfaces that Requirement 8 removes at the user's
  request. They are listed so the deletion is explicit, not silent.
