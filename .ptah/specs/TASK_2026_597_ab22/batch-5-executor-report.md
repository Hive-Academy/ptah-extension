## Risks and edge cases

- **Condenser exceeds 10,000 on a heading-free body.** A heading-free body is cut at its last paragraph break that fits. A single huge paragraph is dropped whole, with the pointer naming "the opening text". If the pointer alone would exceed the cap (pathological path or heading count), the omitted list shrinks to "and N more" and a final clamp applies. The table spec covers every repository role for codex and opencode.
- **Removing `systemPrompt` drops guidance entirely.** The builder spec asserts `projectGuidance` reaches the spawn request exactly once and `systemPrompt` is absent. The utils spec asserts the guidance reaches `buildTaskPrompt` output once on first turn (opencode, and Codex instructions + prompt). The Ptah CLI spec asserts one copy.
- **Fenced code in role files.** Role files contain `## ` headings inside ` ```markdown ` examples (team-leader, backend-developer). Fence-aware splitting never treats those lines as sections and never cuts inside a fence. A spec pins this.
- **R9.7 shared state.** The condenser is pure with no module state. The determinism spec interleaves two different builds.
- **826-byte pin and TASK_2026_515 contract.** Unchanged on the first turn; both specs pass.
