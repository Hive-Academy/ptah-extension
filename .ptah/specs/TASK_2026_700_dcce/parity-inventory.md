## Notes

- The canvas itself is `aria-hidden` and has pointer click/hover only. Keyboard access is through the overlay node buttons (Enter/Space/Escape) and delegated-work list (Arrow Up/Down/Enter). There is no separate canvas keyboard shortcut.
- Overlay node buttons use `aria-controls="command-node-card"` when pinned. Delegated-work rows currently use `aria-current` and roving tabindex but have no `aria-controls`; do not infer that relationship from the requested design.
- On Canvas 2D failure, the stage disappears and the dock/rail/list remain; there is no dedicated fallback stage message in the current page. The scene component still reports the failure.
- Native button activation supplies keyboard access for Approve, Deny, Decline and question choices; Tribunal Confirm adds an explicit focused Enter/Space handler. The ordinary typed-answer input has no custom Enter shortcut.
- Start-view card selection restores a session through `ChatStore.switchSession`; an already-open session in another tab reports a fixed error instead of attaching it to Command Center.
