Install Claude Code

Open a terminal, paste the command for your system, press Enter. The installer prints nothing while it downloads. When the prompt returns, press Re-check.

macOS, Linux, WSL (Terminal)

curl -fsSL https://claude.ai/install.sh | bash

Windows PowerShell (prompt starts with PS)

irm https://claude.ai/install.ps1 | iex

Windows CMD (prompt has no PS)

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

Any system with Node.js 22 or later (do not use sudo)

npm install -g @anthropic-ai/claude-code

Still not found after installing? Open a new terminal, and if Re-check keeps failing, restart Ptah so it picks up the updated PATH.
