## Proposed Removals

None. All four cited completion-page cues have an A5 home.

## Decisions

The Enhanced badge uses the bound run's `enhancedPromptsUsed` fact. The old wizard-only `enhancedPromptsStatus` is not part of A5 state. Raw provider errors remain classified by the reusable outcome summary; A5 does not display the deleted page's raw error list. A completed run with `agentOutcomes: []` has a dedicated "Nothing new was written" message, because the reused grade component only shows its all-kept message when at least one file was processed. The CLI skill invocation mechanism was unavailable in this lane; the local `angular-frontend-patterns/SKILL.md` was read directly and applied.

## Not fixed

Visual inspection and capture execution were excluded by the instruction not to launch the app or Playwright. The capture spec is updated for a later Electron run.
