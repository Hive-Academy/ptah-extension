Submit / form state matrix

Every branch of the `surface.submit` state table (implementation-plan.md Component 5, "Form flow"). Message text stays in text-base-content at normal weight in every branch — only the icon and the left spine carry color — because text-error on base-300 measures ≈3.17:1, which fails WCAG AA for small normal text (design-spec.md "Accessibility", measured-contrast table). This is a deliberate, more conservative reading of that table's own mitigation ("lean on the spine plus icon instead of the text color"); see README.md "Deviations".
