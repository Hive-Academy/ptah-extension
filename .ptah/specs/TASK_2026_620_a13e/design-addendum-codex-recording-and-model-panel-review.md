### Round 0 findings

1. **Blocking — the pinned product settings have no carrier.** The table (design addendum, "Contract and configuration") requires each recording plan's host `settings` payload to set `memory.curatorProvider`/`curatorModel` and `skillSynthesis.<lane>.*`, but no such payload exists. Fix: name the mechanism — either a new host-plan settings map (A1 already owns `plan.schema.ts`) that the host applies to the isolated config (`PTAH_CONFIG_PATH`, `transport/bench-host.entry.ts:15-19`), or a file fixture seeding the config store the CLI workspace provider reads — and add the change to a batch's owned files.

2. **Major — the auth-copy wiring is owned by no batch, and the named file collides with a 619-owned file.** The design adds a `codexAuthSource` "host-runner option" and an `authMount`/`authImport` instruction, but A1's owned files (`host/plan.schema.ts`, `host/bench-host-process.ts`, `recorder/provider-provenance.ts`) do not include `runner/runner-plan.ts` or `runner/run-memory-skills.ts`, which a runner option must touch. 3. **Major — `CODEX_HOME` set in the parent environment silently bypasses the isolated home for Codex auth.** The resolver prefers `env['CODEX_HOME']` over `homedir()` (`libs/backend/auth-providers/src/lib/providers/codex/codex-home-resolver.ts:25`), and the launcher's `isolatedEnv` spreads the parent environment (`host/plan.schema.ts:4-5`; `transport/bench-host.entry.ts:15-17` overrides `HOME`/`USERPROFILE`, not `CODEX_HOME`). Fix: A1 must clear or repoint `CODEX_HOME` in the child environment and assert the resolved auth file lies inside the isolated home.

4. **Major — refresh-token rotation can invalidate the operator's real Codex session, and the design does not say so.** `performRefresh` persists rotated tokens back to the resolved `auth.json` (`libs/backend/auth-providers/src/lib/providers/codex/codex-auth.service.ts:445,507-514`; the refresh response schema allows a rotated `refresh_token`, `:62-66`). Fix: add the risk; instruct the operator to copy a freshly refreshed `auth.json` and re-run `codex login` if the real session breaks, or verify refresh-token reuse semantics before recording.

5. **Major — U2, U3 and U4 are not runnable as specified.** Only U1 has a prompt and an exact output format. 6. **Moderate — the U1 prompt contradicts its own chunking.** The prompt says "give no text outside one CSV row" (addendum, "Eligibility, panel, and blinding"), but each packet holds up to 20 documents (addendum, "U1--U4 mapping" and "Cost"), so a compliant lane must return up to 20 rows. 7. **Moderate — `unresolved-model-panel` exclusions have no cap, so a weak panel silently shrinks the measured set.** The design excludes unresolved items from metrics without reducing the frozen population count and only "reports the exclusion" (addendum, Part B). The trust bar is computed only over rows that loaded (`rubric-ground-truth.ts:371-372,433-465`), so systematic exclusion of hard documents biases agreement upward with no gate.
