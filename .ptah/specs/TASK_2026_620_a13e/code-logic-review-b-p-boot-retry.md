A retry is launched fire-and-forget from the enabled-setting listener ([skill-synthesis.service.ts:662](D:/projects/ptah-extension/.claude-worktrees/task-620-memory-skills-bench/libs/backend/skill-synthesis/src/lib/skill-synthesis.service.ts:662), [skill-synthesis.service.ts:680](D:/projects/ptah-extension/.claude-worktrees/task-620-memory-skills-bench/libs/backend/skill-synthesis/src/lib/skill-synthesis.service.ts:680)). If shutdown calls `stop()` while that retry awaits migration, `performStart()` subsequently sets `started`, registers a session-end handler, starts the curator, and completes after host disposal ([skill-synthesis.service.ts:480](D:/projects/ptah-extension/.claude-worktrees/task-620-memory-skills-bench/libs/backend/skill-synthesis/src/lib/skill-synthesis.service.ts:480), [skill-synthesis.service.ts:495](D:/projects/ptah-extension/.claude-worktrees/task-620-memory-skills-bench/libs/backend/skill-synthesis/src/lib/skill-synthesis.service.ts:495)). Clearing `onStarted` prevents a late trigger callback, but it does not prevent these resurrected service resources; the normal Thoth abort guard only prevents trigger creation ([boot-thoth-runtime.ts:412](D:/projects/ptah-extension/.claude-worktrees/task-620-memory-skills-bench/libs/backend/thoth-runtime/src/lib/boot-thoth-runtime.ts:412)). Add a lifecycle generation/cancellation check across `performStart()` yields, or arrange shutdown to await and re-stop the active run.
