# Wizard and Skills/Library harmony

## Verdict

**Partial harmony, with concrete interference risks.** The wizard writes workspace agents to `.claude/agents/<id>.md`; the user-layer mirror can copy those into workspace-scoped Library agent clones, and the desktop catalog exposes them (`libs/backend/agent-generation/src/lib/services/orchestrator.service.ts:420-424,790-792`; `libs/backend/agent-generation/src/lib/services/user-layer/user-layer-mirror.service.ts:297-321,362-382`; `libs/backend/skill-synthesis/src/lib/skill-registry-catalog.service.ts:39-48`; `apps/ptah-electron/src/activation/plugin-activation.ts:373-402`). However, wizard writes can replace an existing source agent, the Library is desktop-only, a subfolder wizard run can miss the harness root, and agent grades aggregate by kind and slug without workspace filtering (`libs/backend/agent-generation/src/lib/services/file-writer.service.ts:211-232`; `libs/frontend/skill-synthesis-ui/src/lib/components/clones/skill-clones-view.component.ts:159-169`; `libs/backend/rpc-handlers/src/lib/handlers/wizard-generation-rpc.handlers.ts:589-598`; `libs/backend/skill-synthesis/src/lib/skill-task-grade.store.ts:187-199`). TASK_2026_662 explicitly keeps the Library, harness sync, telemetry, review harvesting and agent scorecards while deleting the synthesis pipeline (`.ptah/specs/TASK_2026_662_3eea/implementation-plan.md:5-7`).

## Risks

1. **Serious — source-file overwrite.** A rerun selecting the same template ID targets the same `<id>.md` and writes whenever bytes differ; a user edit in `.claude/agents/<id>.md` is lost. A Library clone edit is a different file: after the source changes, the mirror either fast-forwards an unchanged clone or flags an edited clone as diverged (`libs/backend/agent-generation/src/lib/services/orchestrator.service.ts:790-792,851-874`; `libs/backend/agent-generation/src/lib/services/file-writer.service.ts:211-232`; `libs/backend/agent-generation/src/lib/services/user-layer/user-layer-mirror.service.ts:1539-1589`).
2. **Serious — workspace-root mismatch.** If the wizard runs in a subfolder below the harness root, it writes that folder's `.claude/agents`, while the mirror/catalog use the harness root. The wizard preview itself says these agents do not reach other CLIs; the desktop Library can therefore lack the generated agent (`libs/backend/agent-generation/src/lib/services/orchestrator.service.ts:420-424`; `libs/backend/rpc-handlers/src/lib/handlers/wizard-generation-rpc.handlers.ts:589-598`; `apps/ptah-electron/src/activation/plugin-activation.ts:395-402`).
3. **Serious — cross-workspace grade shadowing.** Agent clones are workspace-scoped, but `getAggregates` filters only `subject_kind` and `subject_slug`. Two projects with `backend-developer` can show the same combined task-review success rate in their separate Library cards (`libs/backend/agent-generation/src/lib/services/user-layer/user-layer-mirror.service.ts:297-321`; `libs/backend/skill-synthesis/src/lib/skill-task-grade.store.ts:187-199`; `libs/backend/rpc-handlers/src/lib/handlers/skills-synthesis-rpc.handlers.ts:2329-2354`).
4. **Moderate — pack/generated filename collision.** The wizard pack installer downloads to workspace `.claude/agents`, and generated agents use that same directory and ID basename. Installing `x.md` after generating `x.md` replaces the source via the pack's atomic rename; generating later replaces it via the file writer if bytes differ (`libs/backend/rpc-handlers/src/lib/handlers/setup-rpc.handlers.ts:914-921`; `libs/backend/platform-core/src/agent-pack-download.service.ts:283-295,391-398`; `libs/backend/agent-generation/src/lib/services/orchestrator.service.ts:790-792`; `libs/backend/agent-generation/src/lib/services/file-writer.service.ts:211-232`).
5. **Moderate — delayed or unavailable Library visibility.** Library cards require desktop and a catalog row; the catalog is synced after mirroring during Electron activation. A generated agent can exist in `.claude/agents` while the Library is unavailable in VS Code, or before a desktop mirror/catalog refresh; pressing the Library refresh button calls `listClones` against registry rows (`libs/frontend/skill-synthesis-ui/src/lib/components/clones/skill-clones-view.component.ts:159-181`; `apps/ptah-electron/src/activation/plugin-activation.ts:328-346,373-402`; `libs/backend/rpc-handlers/src/lib/handlers/skills-synthesis-rpc.handlers.ts:1039-1058`; `libs/frontend/skill-synthesis-ui/src/lib/services/skill-clones-state.service.ts:69-82`).
6. **Moderate — a run is not a grade.** A new agent has no review-derived score until an attributed subagent run and eligible task review are harvested; absent attribution leaves no grade, displayed as `No grade`. A user may mistake wizard generation or a successful tool call for measured task success (`libs/backend/skill-synthesis/src/lib/triggers/skill-trigger.service.ts:506-530`; `libs/backend/skill-synthesis/src/lib/spec-harvester.service.ts:149-185`; `libs/backend/skill-synthesis/src/lib/skill-task-grade.store.ts:187-199`; `libs/frontend/skill-synthesis-ui/src/lib/components/clones/clone-action-gating.ts:240-253`).
7. **Minor — copy and rubric drift.** The Library's empty Agents text says agents arrive from plugins, although the mirror also imports workspace agents. Wizard generation has explicit section rules, while the skill rubric separately calls for routing descriptions, one home per rule and measuring what loads; no rubric input appears in the generation prompt (`libs/frontend/skill-synthesis-ui/src/lib/components/clones/skill-clones-view.component.ts:133-139`; `libs/backend/agent-generation/src/lib/services/content-generation.service.ts:370-402`; `D:/projects/ptah-extension/.claude-worktrees/skills-rubric-sweep/.claude/skills/skill-creator/SKILL.md:12-16`; `D:/projects/ptah-extension/.claude-worktrees/skills-rubric-sweep/.claude/skills/skill-creator/references/prompt-authoring-rubric.md:7-18,61-66`).

## Decisions

- Treat `.claude/agents` as the wizard's source and the scoped user layer as the Library copy; retain the mirror, catalog, telemetry, review harvester and scorecard while removing only the synthesis pipeline (`libs/backend/agent-generation/src/lib/services/orchestrator.service.ts:420-424`; `libs/backend/agent-generation/src/lib/services/user-layer/user-layer-mirror.service.ts:297-321,362-382`; `.ptah/specs/TASK_2026_662_3eea/implementation-plan.md:5-7`).
- Keep task-review evidence as the only success-rate source and show `No grade` when no matched review exists; invocation telemetry remains a separate count (`.ptah/specs/TASK_2026_662_3eea/implementation-plan.md:6-7`; `libs/backend/skill-synthesis/src/lib/skill-scorecard.service.ts:49-68`; `libs/frontend/skill-synthesis-ui/src/lib/components/clones/clone-action-gating.ts:240-253`).
- Preserve the shared agent model setting and Library clone/history/preview methods through the purge; batch 59 explicitly retains them, while batch 62 retains the mirror token (`libs/backend/agent-generation/src/lib/services/orchestrator.service.ts:1091-1100`; `.ptah/specs/TASK_2026_662_3eea/batches.md:1686-1695,1750-1759`).

## Open questions for the user

1. When the wizard would replace an edited `.claude/agents/<id>.md` or a pack-installed file, should it default to keeping the existing source, or present a per-file replacement choice? Current writes replace differing bytes, and both features target that directory (`libs/backend/agent-generation/src/lib/services/file-writer.service.ts:211-232`; `libs/backend/rpc-handlers/src/lib/handlers/setup-rpc.handlers.ts:914-921`).
2. Should a Library agent score follow the workspace-specific agent file, or intentionally combine same-slug task reviews from all workspaces? Clones are scoped by workspace while grade aggregation currently is not (`libs/backend/agent-generation/src/lib/services/user-layer/user-layer-mirror.service.ts:297-321`; `libs/backend/skill-synthesis/src/lib/skill-task-grade.store.ts:187-199`).
3. Should wizard-created agents be visible in the VS Code host, or is desktop Library visibility after mirror/catalog sync sufficient? The current Library screen explicitly gates itself to desktop (`libs/frontend/skill-synthesis-ui/src/lib/components/clones/skill-clones-view.component.ts:159-169`; `apps/ptah-electron/src/activation/plugin-activation.ts:373-402`).
