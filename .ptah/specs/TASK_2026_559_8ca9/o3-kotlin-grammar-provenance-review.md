The independent hash/load observations below can inform the correction but do not replace the missing source-build/full-corpus evidence.

2. **Serious — the source-build procedure does not establish reproducibility.** Document §3 uses `tree-sitter-cli@0.24.<x>` and an unspecified Docker/emsdk environment; §4 records version labels only. It accepts matching ABI and a small corpus as proof of equivalence when binary hashes differ. Such a smoke test cannot establish that an arbitrary prebuilt WASM was produced by the named source, nor reproduce its bytes. Current integrity validation at `scripts/copy-wasm.js:133`–`:145` checks only a supplied binary digest, and the manifest source identity at `scripts/tree-sitter-grammars.json:197`–`:205` has no reproducible build recipe. **Required change:** pin the exact CLI, emscripten/container identity, source input, generation/build commands, flags and relevant environment; record repeated clean-build hashes and the resulting relationship to the shipped artifact. If the upstream prebuilt cannot be reproduced byte-for-byte, explicitly label that limitation and obtain an explicit acceptance of that provenance limitation or ship the reproducibly built source artifact with its own hash. Retain corpus equivalence as a compatibility check, not provenance proof. No rebuild was attempted during this read-only review.

3. **Serious — the licence/provenance packaging gates require unassigned code changes.** Document §1 says `copy-wasm.js` copies the licence into every dist, and §5 says it compares `PROVENANCE.json` and all packed verifiers require the licence. Current `scripts/copy-wasm.js:133` checks that the licence source exists, `:135`–`:141` checks the WASM against the manifest only, and `:149`–`:169` copies only WASM files. Electron's required list is WASM-only (`apps/ptah-electron/scripts/verify-packed-wasm.js:63`); CLI's likewise (`apps/ptah-cli/scripts/verify-packed-wasm.cjs:48`); the VSIX verifier even rejects non-WASM required paths (`apps/ptah-extension-vscode/scripts/verify-packed-wasm.cjs:24`). Batch 30k's named files at `batches.md:3960` and `:3970` do not include these changes. **Required change:** explicitly amend the implementation footprint to include the copy script, all three verifier scripts and their self-tests. Define licence destination, copying and hash validation, provenance-file lookup, and negative tests for missing/empty/changed licence and mismatched manifest/provenance/WASM hashes. Mark these as new work, not behavior inherited from 28a/28b. Replace the illustrative row with the current schema (`filename`, `licence`, `bytes`, `source.kind/package/version/path/licenceFile/sha256`), reconcile the tools paths with the current assets paths, and remove `provenancePending` only when the required evidence is complete.
