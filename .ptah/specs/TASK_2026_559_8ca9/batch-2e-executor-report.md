## Write-path trace

Raw output goes to the spool file `<spool root>/.ptah/tmp/mcp-out/<id>-<ms>-<hex>.txt`. The trailer names that path:
the absolute path, or a relative one when the absolute path is too long. The agent reads the file with its Read
tool. No setting or config file is written.
