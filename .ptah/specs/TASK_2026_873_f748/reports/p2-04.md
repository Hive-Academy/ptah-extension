## Decisions

- New file `context/incremental-scope.service.ts`: needed for one validated, bounded calculation of changed paths, dependents, and prior failures. Alternative was repeating the calculation in the stage; the named batch explicitly requested a service. Reversible: yes.
- New file `context/incremental-scope.service.spec.ts`: focused regression coverage for the new planner. Reversible: yes.
- Use 0065 `review_attempts` completed/succeeded rows and `review_findings` open rows; no migration or publication files changed. Alternative was adding storage fields, which was prohibited and unnecessary. Reversible: yes.
- Same-head reruns use an empty new-commit diff and recheck open failures; this follows the current-head identity rather than fabricating changes. Reversible: yes.
