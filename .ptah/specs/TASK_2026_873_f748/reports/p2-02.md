## Public contract for P2-03

`IGitHubReviewPublicationPort.publish(target, walkthrough, overview, candidates, validRightAnchors)` is exported from `@ptah-extension/review-github`. `target` carries repo, PR number and analyzed SHA. `candidates` carry stable `findingId`, path, line and body; `validRightAnchors` is a set of `rightAnchorKey(path, line)` values computed from the current diff. `PublicationResult` returns the walkthrough and review IDs plus deferred candidates. Resolve `REVIEW_GITHUB_TOKENS.PUBLICATION_PORT`; bind `REVIEW_GITHUB_TOKENS.PUBLICATION_GUARD` to a live `ReviewPublicationGuard` before resolving it. The guard must enforce global/repo pause, publication enablement, trust and config validity. The adapter itself also reads the current PR head before each mutation.

## Decisions

- Kept the publication contract local to review-github because review-core is concurrently owned by P2-03. Alternative: edit the shared read port; evidence: batch file ownership and P1's existing read adapter. Reversible by moving the interface after parallel work settles.
- Used GitHub body markers plus bot-owned read endpoints for retry reconciliation. Alternative: trust an in-memory or persisted ID alone; evidence: AC-11.3 requires recovery after an unknown timeout. Reversible.
- Used a caller supplied validated RIGHT-anchor set. Alternative: parse GitHub diff inside the mutation adapter; evidence: AC-7.3 and review-core's diff validation responsibility. Reversible.

## Open questions and limits

- P2-03 must apply verifier, confidence and severity thresholds before calling this port, record suppression reasons, serialize per-PR publication, and persist returned IDs/outcomes. This adapter caps and deduplicates only the candidates it receives.
- P2-03 must redact local paths, other credentials and untrusted instruction text before passing publication text. This adapter rejects only the configured bot token canary; it cannot identify arbitrary secrets.
- An external concurrent writer can race the read-before-create check. P2-03's serialized per-PR outbox is needed to prevent duplicate reviews under concurrency.
