## Contract for P2-06

Add and allowlist these RPCs, including shared method union and Electron registration. Validate all parameters and results at host boundary:

| Method | Params | Result | Requirement |
| --- | --- | --- | --- |
| `review:getBotIdentity` | `{}` | `{ login: string; scopes: string[]; connectedAt: string; verifiedAt: string \| null } \| null` | Never include token or secret-derived text. Return verified bot metadata. |
| `review:setBotToken` | `{ token: string }` | `{ ok: true }` | Store through platform secret storage; never log or echo token. |
| `review:clearBotToken` | `{}` | `{ ok: true }` | Remove stored token and invalidate identity. |
| `review:rerun` | `{ attemptId: string; dryRun: boolean }` | `{ attemptId: string }` | Create a new attempt; enforce live eligibility and head/kill guards on host. |

Existing `review:getSettings` must continue to return only `{ settings, hasToken }`, with no token. Existing `review:updateSettings` must validate the maintainer allowlist and repository rollout settings. Existing `review:setPublicationPause` must be authoritative for pause state.

## Decisions

- Kept CodeRabbit coexistence as copy, not a toggle, per design spec. Reversible.

## Fix round 1

- Cause: `loadSettings()` calls `review:getSettings` and then `review:getBotIdentity`. The two-response pause tests supplied the pause `{ ok: true }` as the second response, so identity consumed it. The later pause call received `undefined` and failed result parsing. The `review:setPublicationPause` schema itself accepts `{ ok: true }`.
- `review-runs.store.spec.ts:109?111,125?134` now provides a separate null identity response before the pause response or rejection. The failure test checks that the caught error reaches `LoggingService`.
- `review-runs.store.ts:2,21,185?188` now logs the real caught error through `LoggingService` while retaining the user-facing `pauseError` flag.
- Verification: `npx jest --config libs/frontend/review-runs-ui/jest.config.ts --coverage=false review-runs --runInBand` passed: 7 suites, 22 tests. Scoped `ptah_get_diagnostics` found no diagnostics in the changed files; five existing BigInt target errors remain in unchanged shared sibling files.
