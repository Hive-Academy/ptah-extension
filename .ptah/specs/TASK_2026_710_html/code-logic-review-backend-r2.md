## New defects

1. Non-blocking. A published page can replace itself with a different artifact. `isAllowedArtifactFrameUrl` accepts every host that matches the id pattern (`artifact-frame-guard.ts:5-7`). `will-frame-navigate` uses only that predicate (`main-window.ts:73-76`). `readBytes` serves any id that has metadata (`electron-artifact-store.ts:190-195`; resolver `main.ts:135-137`). Failure: HTML that already contains another artifact id assigns `location` to `ptah-artifact://<that-id>/index.html`. The iframe shows that document. The load is not a network request, and the id is not guessable. Query, hash, userinfo, and a non-artifact scheme stay cancelled or 404 (`artifact-frame-guard.ts:7`; `artifact-protocol.ts:41-52`).

2. Non-blocking. A missing or unreadable session workspace is reported as a bad HTML path. `fs.realpath(scope.workspaceRoot)` maps every failure to `INVALID_PATH` (`electron-artifact-store.ts:63-66`). The tool sentence is "Artifact path must name a readable HTML file inside the caller workspace." (`artifact-tool-handlers.ts:24`). Failure: the session's `projectPath` is gone or not readable, and the agent published inline `html`. Nothing is written. The model is told to fix the path.

## Five logic questions

1. Silent success. A cold list no longer turns a non-`ENOENT` directory failure into `{ artifacts: [] }` (`electron-artifact-store.ts:206-208`). An unknown or workspace-less session still returns an empty success (`artifact-rpc.handlers.ts:55-56`). That is the stated contract for an unknown id. A list of more than 200 records succeeds and omits the rest (`electron-artifact-store.ts:178`).
2. Unexpected user action. Switching chats reloads that tab id and lists that registry row's workspace. The sheet reads the same key. The remaining surprise is defect 1: a script that knows another id shows that artifact inside this card.
3. Wrong answer without an error. A path file that is not UTF-8 and is under 2 MiB is still stored and served as `text/html; charset=utf-8` (`artifact-protocol.ts:7-8`). That predates this round and is not one of the fourteen. The advertised schema can describe `title` plus both `html` and `path`; the handler rejects that body (`artifact-tool-handlers.ts:39-40`).
4. Dependency failure. Quota and write failures are `QUOTA` and `IO_ERROR` with fixed sentences (`artifact-tool-handlers.ts:28-29`). List IO becomes `PERSISTENCE_UNAVAILABLE` (`artifact-rpc.handlers.ts:64`). A workspace `realpath` failure is still the path sentence (new defect 2). `openExternal` rejection stays `{ opened: false }` (`artifact-rpc.handlers.ts:78-83`).
5. Unspecified requirement. The fixed decisions (new id, no `savedPath` on the model or webview, Electron only, nonce on the bridge) match the code that was checked. The list cap still has no truncated flag (defect 10).
