## Decisions

- **Holder kind source.** I chose `PLATFORM_INFO` over the suggested `HOST_KIND` because `HOST_KIND` is not registered in the CLI container. This is reversible.
- **Bounded reducer retry.** I chose a retry count over adding an error code to the action because a count keeps the action type unchanged for the Phase D host. If Phase D wants to classify errors, it can add an error code later. This is reversible.
- **Lock exit fix.** I unref'd the lock servers rather than adding a CLI dispose path. This is the smallest change, it covers every host, and Electron is unaffected because its app keeps the process alive. This is reversible.
