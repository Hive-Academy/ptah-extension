# Producer correction handoff

## Changes

- SDK accepted-turn contributions now carry the launch route's provider ID through `StreamTransformer` and `SessionStatsOwnerService`.
- SDK accepted results whose token and cost deltas are all zero no longer create a ledger event.
- Native Codex price corrections now use the cumulative accepted price in the idempotency key. Equal positive deltas on successive corrections therefore get distinct keys. A transition from an unknown prior price to a known accepted price captures the newly known amount.
- Added focused producer regression coverage for provider attribution, zero-only results, and Codex unknown-to-known and successive equal-price corrections.

## Decisions

- Use the frozen `capacityRoute.providerId` for SDK attribution; it is already resolved at launch and avoids a second provider lookup. This is reversible.
- Use the accepted Codex cumulative price for correction identity; the previous delta alone collides for two equal corrections. This is reversible.

## Verification

- Agent SDK Jest: 2 suites, 244 tests passed (`--coverage=false --runInBand`). A two-worker attempt could not spawn workers (`EPERM`), so the serial run was used.
- `npx tsc --noEmit --project libs/backend/agent-sdk/tsconfig.lib.json`: passed.
- Scoped `ptah_get_diagnostics` was unavailable after two timeouts; direct project TypeScript compilation passed. Nx plugin loading failed with `spawn EPERM`.
- No git commands run. No `cli-agent-runtime` source change was needed: its lane producer already skips zero-only usage and carries provider ID.

## Unmet requirement

- An accepted SDK result with a lower repriced cumulative cost still cannot subtract previously persisted cost. The producer port and SQLite adapter require nonnegative micro-USD values, and the current ledger stores additive per-turn events. Fixing that requires a coordinated ledger replacement or signed correction contract in `persistence-sqlite`, outside the assigned package scope. The current producer still preserves the new token delta and marks its decreased cost unknown; it does not claim a corrected ledger total.
