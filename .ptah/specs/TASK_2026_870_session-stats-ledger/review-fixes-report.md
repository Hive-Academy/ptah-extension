## Decisions

- **Workspace ownership:** the canonical `sessions.workspace_key` wins when a session exists; orphan lane turns use their captured workspace key. This preserves the existing session boundary. Reversible by a later ownership migration.
- **Native Codex identity:** checkpoint `run_id` is the root thread; a Codex CLI lane uses its native session ID. The external Codex rollout uses that same native ID. A bounded workspace and time query avoids suppressing unrelated external usage. Reversible.
- **SDK decreases:** an absolute run snapshot resets only prior costs for that run; prior token events remain. This avoids signed money inputs and preserves per-turn counts. Reversible with a later cost-fact schema.
- **Overflow:** 256 pending writes is a fixed in-memory bound. A full queue rejects and logs the event; shutdown flush reports the loss. The producer catches rejection so the stream continues. Reversible by adding a durable outbox.
- **Historical coverage:** all Ptah ledger summaries remain partial because no JSONL backfill exists and the first live capture does not prove every later event was recorded. The reason includes the first write date. Reversible if durable coverage proof is added.
