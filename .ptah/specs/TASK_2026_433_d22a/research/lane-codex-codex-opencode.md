[Subagent documentation](https://learn.chatgpt.com/docs/agent-configuration/subagents).

No explicit developer-instruction size ceiling is documented; model context and argv transport constrain it. `AGENTS.md` has a separate `project_doc_max_bytes` limit. [Configuration reference](https://learn.chatgpt.com/docs/config-file/config-reference).

## OpenCode

- **1. Native selection:** Yes: `opencode run --agent <name> "<task>"`. Definitions: `.opencode/agents/<name>.md` or `~/.config/opencode/agents/<name>.md`; Markdown body supplies instructions, YAML `description` is documented as required, and filename determines name. Use `mode: primary` or `all` (default). JSON/JSONC alternatively defines `agent.<name>`. [CLI](https://opencode.ai/docs/cli/), [agents](https://opencode.ai/docs/agents).
- **2. Semantics:** Root selection is deterministic **only for eligible definitions**. Upstream `run.ts` rejects missing agents and `mode: subagent`, warns, and falls back to default. [Selection source](https://github.com/anomalyco/opencode/blob/dev/packages/opencode/src/cli/cmd/run.ts#L567). A custom prompt **replaces the provider’s default prompt component**; other system/project instructions remain appended. Agent permissions restrict tools, and agent model settings configure model choice, subject to explicit run overrides. [Prompt assembly and tool filtering](https://github.com/anomalyco/opencode/blob/dev/packages/opencode/src/session/llm/request.ts#L50).
- **3. Injection alternative:** No fallback is necessary if Ptah supplies an eligible definition. Without disk files, add `agent.<role> = {description, mode:"primary", prompt:roleBody}` to `OPENCODE_CONFIG_CONTENT`, then select it with `--agent`. Inline configuration merges over normal project configuration; managed settings can override it. No role-specific size limit was established. [Configuration](https://opencode.ai/docs/config/).
- **4. Current adapter/change:** [opencode-cli.adapter.ts:413](/D:/projects/ptah-extension/libs/backend/cli-agent-runtime/src/lib/cli-agents/cli-adapters/opencode-cli.adapter.ts:413) builds `run --format json [--auto] [--model …] [--dir …] [--session …] <taskPrompt>`; `spawnCli` executes it at 459. Insert `args.push('--agent', role)` before the final prompt. Extend existing `OPENCODE_CONFIG_CONTENT` construction at 444–451 to merge the role definition alongside MCP configuration, including when no MCP port exists.
- **5. Harness compatibility:** **Coverage gap:** `rg -n 'opencode' libs/backend/harness-sync/src` returned no matches. Ptah currently writes no OpenCode definitions. Adding the flag alone cannot select Ptah-generated roles; supply inline configuration or add an OpenCode transformer. Singular `agent/` is also supported for compatibility. [Configuration paths](https://opencode.ai/docs/config/).
- **6. Confidence/experiment:** High from current documentation/source; medium for release compatibility because OpenCode is not installed and source is moving `dev`. Confirm on the intended version with one inline primary role containing a unique marker and denied edit permission; inspect selected-agent metadata, prompt placement, and denied-tool behavior.
