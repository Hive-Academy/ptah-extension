The **Setup** tab sets up Ptah for your project. Its home page has the heading **Set up Ptah for your work** and three paths.

![Setup overview](/screenshots/setup-hub.png)

## Open Setup

Open a workspace, then click **Setup** in the tab bar. When no folder is open, Setup shows **No folder is open. Open one to start a path.**

## The three paths

| Path                        | Use it when                                         | Page                                       |
| --------------------------- | --------------------------------------------------- | ------------------------------------------ |
| **Analyze current project** | You already have code. Ptah reads the workspace, recommends agents, writes them, and prepares project guidance. | [Analyze current project](/setup/setup-wizard/) |
| **New project**             | You start from an empty folder. Answer short questions and review a proposed agent, skill, and toolchain setup. | [New project](/setup/new-project/)         |
| **AI team builder**         | You want to describe the team and tune the proposed configuration with the agent. | [AI team builder](/setup/ai-team-builder/) |

## Status

Below the paths, Setup shows status chips for the open workspace:

- **Workspace analyzed** or **Not analyzed yet**.
- The number of agents that are set up, or **No agents yet**.

If a run stopped before it was done, Setup shows it so that you can continue it.

## Get ready

Click **Review your connection and settings** to open the **Get ready** step again. It checks that Claude Code or Codex is installed and signed in. See [First launch](/getting-started/first-launch/#get-ready).
