# Git & Version Control

PtahCode treats git as part of your workspace. Each open workspace that contains a git repository gets:

- A **git watcher** that updates the status when git changes files in `.git/`.
- The **Git dock** with the branch, upstream status, stashes, and changed files.
- A **review view** with diffs, staging, commits, history, and worktrees.

## Quick reference

| Feature          | Where to find it                                       |
| ---------------- | ------------------------------------------------------ |
| Current branch   | Git dock header                                        |
| Fetch, Pull, Push | Git dock header buttons                               |
| Stashes          | **Stashes** in the Git dock header                     |
| Diffs            | **Changes** tab of the review view                     |
| Commit           | **Commit** tab of the review view                      |
| History          | **History** tab of the review view                     |
| Worktrees        | **Task** tab of the review view                        |
