# Switching Workspaces

You can keep several workspaces open. One workspace is active at a time.

## From the workspace sidebar

Click a workspace in the workspace sidebar to make it active.

![Workspace quick switcher](/screenshots/workspace-switcher.png)

When you switch:

- The canvas shows the board of the new workspace. Each workspace has its own board.
- Sessions in the other workspace continue to run. The sidebar marks a workspace that has a running session.
- The git status changes to the new workspace.

## Usage counters

Provider quotas and usage are per provider, not per workspace. A switch does not reset usage counters.
