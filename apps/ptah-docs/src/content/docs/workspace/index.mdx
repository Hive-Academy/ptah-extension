# Workspace

A **workspace** in PtahCode is a project folder on disk. Agents analyze, edit, and run commands in it. You can keep several workspaces open. One workspace is active at a time.

When you open a workspace, PtahCode:

- Adds the folder to the workspace sidebar and saves the list for the next launch.
- Imports recent Claude sessions for the folder. Refer to [Session auto-import](/sessions/auto-import/).
- Copies your agents, skills, and MCP servers into the folders of other CLIs. Refer to [Syncing agents to CLIs](/agents/syncing-to-cli/).
- Starts the git watcher so that branch and file status stay current.
