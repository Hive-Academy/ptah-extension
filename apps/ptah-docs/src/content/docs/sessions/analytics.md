# Session Analytics

The usage dashboard shows the tokens and cost of your sessions for a range of days. All data comes from your local sessions.

## Open the dashboard

Click **Analytics** in the tab bar. To return, click the back arrow (**Back to chat**).

## What the dashboard shows

- **Totals** for the selected range: sessions, messages, tokens, and cost.
- **Daily usage** as a chart. Select the chart metric to change what it plots.
- **Cost share** by model or by provider.
- **Cache savings**, the cost that prompt caching saved.
- A **session** table with the model, the token count, the cost, and the last activity of each session.

Click **Refresh usage** to load the latest data.

## Price sources

Each cost shows where its price comes from:

- **Provider reported**: the provider sent the cost.
- **Model priced**: PtahCode calculated the cost from the model price.
- **Unpriced**: no price is available. PtahCode still counts the tokens.
