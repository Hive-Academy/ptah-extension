# Session Management

Each conversation in PtahCode is a **session**. A session keeps its messages, tool calls, and sub-agent runs. You can close the app and resume the session later.

![Sessions overview](/screenshots/sessions-overview.png)

## Why sessions matter

- **Context stays separate.** Each task gets its own context.
- **Work is measurable.** Tokens and cost are counted for each session.
- **History stays local.** PtahCode keeps session data on your machine.

## Where sessions live

The provider runtime keeps the transcript. For Claude sessions, this is `~/.claude/projects/`. PtahCode keeps the organization data of each session (status, priority, pin, and task links) in its local SQLite database.
