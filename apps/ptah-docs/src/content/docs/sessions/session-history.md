# Session History

The **Previous sessions** view lists the sessions of the current workspace. Use it to find and open an earlier session.

![History panel](/screenshots/sessions-history.png)

## Search

Type in **Search sessions...** to find sessions by name. Click **Clear search** to show all sessions again.

## Date range

Toggle the date filter, then set **From** and **To**. The **To** date must be on or after the **From** date.

## Filters

| Filter           | What it does                                        |
| ---------------- | --------------------------------------------------- |
| Status           | Shows sessions with the selected workflow status.   |
| Priority         | Shows sessions with the selected priority.          |
| Pinned only      | Shows pinned sessions only.                         |
| Has pull request | Shows sessions that are linked to a pull request.   |
| Task id          | Shows sessions linked to a task, such as `TASK_2026_...`. |

Click **Clear all filters** to remove all filters.

## Sort and group

- Sort by **Last active**, **Created**, **Name**, or **Priority**.
- Group by status, task, or parent session, or select **No grouping**.

## Open a session

Click **Open in a tab** on a row to open the session.
