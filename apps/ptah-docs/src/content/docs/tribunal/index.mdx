# Tribunal

Tribunal runs through the `tribunal` skill in your main chat. Ask for a move in plain language, or use a prompt such as `/tribunal council: should we change our API?`. The conductor discovers installed CLI agents and configured Ptah CLI providers with `ptah_agent_list`, or accepts the lanes you name in plain text. It announces the selected panel, rounds, and estimated paid call count, then waits for your confirmation before spawning lanes. A vendor mentioned in these guides is an example, never a guaranteed installed lane.

## Choose a workflow

- [Council](/tribunal/council/) asks independent vendors one question, cross-critiques the answers, and gives a cited verdict.
- [Forge](/tribunal/forge/) gives each vendor the same coding task in an isolated worktree, then cross-reviews the diffs.
- [Race](/tribunal/race/) runs independent attempts against a fixed rubric and verifies the highest ranked candidate.
- [Crucible](/tribunal/crucible/) pairs an executor with an independent judge for a bounded revision loop.
- [Relay](/tribunal/relay/) assigns plan, architect, implement, and review phases to CLI lanes through the `orchestration` skill.

## Pin a panel

Name installed lanes in your chat request, for example: "Run a Council with my installed Codex and Kimi lanes on this API decision." The conductor resolves each name against `ptah_agent_list` and repeats the exact panel before any paid calls. You can also ask it to choose for vendor diversity. If fewer than two independent families are available, it explains the limit and asks whether to continue with one voice or stop. For Crucible, name an executor and a judge from different families; for Relay, name a lane for each phase if you want to pin roles.

## Review the result

The conductor reports progress, individual evidence, disagreements, and the verdict in the same chat. Task work and review artifacts are saved in a `.ptah/specs/TASK_*` folder; ask for the folder path or open it from the chat result. For code moves, inspect the diff and verification before approving any integration or commit. To stop work, tell the conductor to stop the run; it stops live lanes with `ptah_agent_stop` and reports what was completed.

Enable `tribunal` and `agent-lanes` from `ptah-core`. Crucible and Relay also need `orchestration`. If a required skill is unavailable, the conductor identifies it before proceeding.
