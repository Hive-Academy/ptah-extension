# Automation

PtahCode can do work while you are away from the desktop app. Both automation features are in the **Thoth** panel.

<CardGrid>
  <Card title="Cron Scheduler" icon="seti:clock">
    Run a prompt on a cron schedule as a headless session. Jobs stay after restarts, and missed slots catch up after sleep. [Learn more →](/automation/cron/)
  </Card>
  <Card title="Messaging Gateway" icon="comment-alt">
    Drive PtahCode from Telegram, Discord, or Slack. [Learn more →](/automation/messaging/)
  </Card>
</CardGrid>

Both features store their data in `~/.ptah/ptah.db` and their settings in `~/.ptah/settings.json`. The cron scheduler is enabled by default, but no job runs until you create one. The messaging gateway is disabled until you start a platform.
