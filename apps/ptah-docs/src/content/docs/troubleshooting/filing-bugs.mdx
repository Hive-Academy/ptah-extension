Bugs are tracked on GitHub: [https://github.com/Hive-Academy/PtahCode/issues](https://github.com/Hive-Academy/PtahCode/issues).

## Before you file

1. Search the existing issues. Your problem can already be known.
2. Make sure that the problem occurs on the latest version.
3. Try a different workspace. Some problems occur only in one workspace.

## What to include

| Section                    | What to include                                                  |
| -------------------------- | ---------------------------------------------------------------- |
| **What happened**          | A one-sentence summary.                                          |
| **Expected**               | What you expected instead.                                       |
| **Steps**                  | Numbered, minimal steps. Start from "start Ptah".                |
| **Environment**            | Ptah version, OS, and the providers that you use.               |
| **Logs**                   | The `Ptah-YYYY-MM-DD.log` file of the day, if it shows the problem. See [Logs & diagnostics](/troubleshooting/logs-and-diagnostics/). |
| **Screenshot / recording** | Useful for problems in the UI.                                   |

## Template

```markdown
### What happened

<one-sentence summary>

### Expected

<what should have happened>

### Steps to reproduce

1.
2.
3.

### Environment

<Ptah version, OS, providers>

### Logs / screenshots

<attach files>
```

## Security issues

<Aside type="caution">
Do not put security issues in the public tracker. Send them to **security@ptah.live**. See `SECURITY.md` in the repository.
</Aside>

## Feature requests

You can request features on the same tracker. Describe the problem that you want to solve, not only the feature that you have in mind.
