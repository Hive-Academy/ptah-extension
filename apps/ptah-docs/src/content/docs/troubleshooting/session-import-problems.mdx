---
title: Session Import Problems
description: Fix problems with the import of Claude Code sessions.
---

Ptah imports your Claude Code conversations from `~/.claude/projects/`, so you keep your history.

## How the import works

When Ptah starts and when you open or switch a workspace, Ptah scans `~/.claude/projects/` for the folder that belongs to the workspace path. Each session is a `*.jsonl` transcript. Ptah imports up to 50 recent sessions. The session list fills while the import runs.

## Common problems

**Symptom:** No sessions appear, but `~/.claude/projects/` contains folders.
**Likely cause:** The workspace path in Ptah is not the path that Claude Code used.
**Fix:** Open the workspace from the same absolute path. If you moved the project, the old sessions belong to the old path.

---

**Symptom:** Old sessions are missing.
**Likely cause:** Ptah imports only the most recent sessions.
**Fix:** This is expected.

---

**Symptom:** A session shows as empty.
**Likely cause:** The `.jsonl` transcript is damaged or was cut off.
**Fix:** Open the file in a text editor. Each line must be a complete JSON object.

---

**Symptom:** Attached files are missing after the import.
**Likely cause:** The transcript refers to absolute paths that do not exist on this machine.
**Fix:** This is expected for sessions from another machine. The text of the conversation stays.

## Where the files are

| OS      | Path                               |
| ------- | ---------------------------------- |
| Windows | `C:\Users\<you>\.claude\projects\` |
| macOS   | `/Users/<you>/.claude/projects/`   |
| Linux   | `/home/<you>/.claude/projects/`    |

The import only reads these files. It does not change them.
