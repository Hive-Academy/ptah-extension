Ptah writes its log to the Electron logs folder. It starts a new file each day.

## Log file locations

| OS      | Path                                        |
| ------- | ------------------------------------------- |
| Windows | `C:\Users\<you>\AppData\Roaming\Ptah\logs\` |
| macOS   | `/Users/<you>/Library/Logs/Ptah/`           |
| Linux   | `/home/<you>/.config/Ptah/logs/`            |

The log of the day is named `Ptah-YYYY-MM-DD.log`.

## Log level

The default level is `info`. For more detail, start Ptah with the `PTAH_LOG_LEVEL` environment variable. The levels are `debug`, `info`, `warn`, and `error`.

```bash
# macOS
PTAH_LOG_LEVEL=debug /Applications/Ptah.app/Contents/MacOS/Ptah

# Linux
PTAH_LOG_LEVEL=debug ./Ptah-*.AppImage
```

On Windows, set `PTAH_LOG_LEVEL` as a user environment variable, then start Ptah.

## DevTools

Ptah is an Electron app. To open Chromium DevTools, select **View → Toggle Developer Tools**, or press `Ctrl+Shift+I` (Windows and Linux) or `Cmd+Option+I` (macOS).

The **Console** tab shows errors in the app window.

## Reset the database

If the local database is damaged, select **Help → Database → Reset Database...**. This deletes all memories, skills, cron jobs, and gateway data. Ptah makes a backup first. Use it only when other fixes fail.

## Before you share a log

Ptah does not write secret values to the log. But a log can contain file paths, workspace names, and file contents. Read a log before you attach it to a bug report.
