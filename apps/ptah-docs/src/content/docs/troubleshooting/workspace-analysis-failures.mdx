title: Workspace Analysis Failures
description: Permissions, symlinks, and very large repositories.
---

When you open a workspace, Ptah indexes its files. [Analyze current project](/setup/setup-wizard/) also scans the workspace to detect the stack. Some environments cause problems.

## Permissions

**Symptom:** "Permission denied" errors during analysis on macOS or Linux.
**Likely cause:** The workspace contains files that you cannot read.
**Fix:** Correct the ownership of the files, or add the paths to `.gitignore`.

---

**Symptom:** "Access is denied" on Windows for `System Volume Information` or recycle bin folders.
**Likely cause:** The workspace is a drive root (for example `D:\`).
**Fix:** Open a project folder, not a drive root.

## Symlinks

**Symptom:** Files in a symlinked folder do not show in search.
**Likely cause:** The symlink target is outside the workspace root.
**Fix:** Open the target folder as its own workspace, or move it into the workspace.

## Large repositories

**Symptom:** Analysis takes a long time on a large monorepo.
**Likely cause:** Many files in folders such as build output, dependencies, and generated data.
**Fix:** Ptah reads ignore patterns from `.gitignore` and from other ignore files (`.prettierignore`, `.eslintignore`, `.npmignore`). Add the large folders that you do not need to `.gitignore`.

---

**Symptom:** "Out of memory" during analysis.
**Likely cause:** Too many large binary files in the workspace.
**Fix:** Ignore folders with images, videos, and data dumps.

<Aside type="tip">
Ignore files use the `.gitignore` syntax, with negation (`!pattern`) and nested ignore files.
</Aside>

## Network drives

**Symptom:** Analysis is slow or inconsistent on an SMB or NFS mount.
**Likely cause:** File system events are not reliable on network mounts.
**Fix:** Work on a local copy of the project.

## Antivirus

**Symptom:** Analysis stops for some seconds at a time on Windows.
**Likely cause:** Real-time antivirus scans each file that Ptah reads.
**Fix:** Add the workspace folder to your antivirus exclusions.
