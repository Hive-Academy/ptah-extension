# SKILL.md Anatomy

A user-layer skill has a `SKILL.md` file under `~/.ptah/user/skills/<slug>/`. The file starts with YAML frontmatter and continues with the skill instructions in Markdown.

```markdown title="~/.ptah/user/skills/api-error-triage/SKILL.md"
---
name: api-error-triage
description: Triage failing HTTP calls. Use when a user asks why an API call failed.
---

# API Error Triage

## Identify the failing call

Read the request and response, then check the server log.
```

| Field         | Purpose                                                              |
| ------------- | -------------------------------------------------------------------- |
| `name`        | Skill name. Use the directory slug.                                  |
| `description` | Short description that helps the agent choose when to use the skill. |

You can edit the body in the Skills Library. Library history stores earlier versions, so a saved edit can be reverted. [MCP & Skills → Skills](/mcp-and-skills/skills/) explains how Ptah loads skill files.
