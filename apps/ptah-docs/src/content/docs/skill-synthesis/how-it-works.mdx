# How the Skills Library Works

## Copies and upstream changes

Ptah keeps user-layer copies of shipped skills, agents, and commands. The Library lists those copies. You can open a copy, edit its body, and save it.

When a shipped source changes after you edit a copy, the Library marks the copy as diverged. **Rebase to upstream** updates it against the source. **Keep mine** resolves the divergence while retaining your content.

## Enhancement and history

When enabled, **Enhance now** generates a proposal for a Library item. The action depends on recorded use and a cooldown. You can inspect the preview and apply it. Applying the proposal writes the new body and adds a history snapshot. You can inspect history and revert to an earlier version. Enhancement is a manual action.

## Use and success

Skill invocation telemetry records use when skills.telemetry.enabled is on. That setting defaults to on and remains separate from the Skills pause switch, skillSynthesis.enabled.

A success rate comes from graded task reviews under the current workspace's .ptah/specs task folders. It is passed grades divided by all graded reviews for that item in that workspace. With no graded review, the Library shows **No grade**, even if the item has been used.

See the [Skills Library](/skill-synthesis/) for where to find these controls.
