# The Skills Tab

Open **Thoth → Skills** in Ptah desktop. The tab shows the Library of skills, agents, and commands. In the VS Code extension, it shows a notice directing you to Ptah desktop.

The Library lists user-layer copies of shipped items. Select a card to open its drawer, read or edit the body, and view its history. You can restore an earlier version from history.

If a shipped source changes after you edit its copy, the Library marks the copy as diverged. Open it to **Rebase to upstream** or **Keep mine**. Keeping your version resolves the divergence without changing its content.

**Enhance now** requests a manual proposal when the item has enough recorded use and its cooldown has passed. Review the preview before applying it. Applying the proposal saves a history snapshot. If Skills is paused, enhancement is unavailable.

**Success** uses graded task reviews for the current workspace. With no graded review, the Library shows **No grade**.

The **Skills** switch uses `skillSynthesis.enabled`. The separate **Skill telemetry** switch uses `skills.telemetry.enabled`. Telemetry defaults to on and can keep recording skill use while Skills is paused.

See [Settings](/skill-synthesis/settings/) for the enhancement provider, model, and timeout.
