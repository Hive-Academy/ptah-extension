# Skills Library

Open **Thoth → Skills** in Ptah desktop to manage the Library. The Skills tab shows skills, agents, and commands. In the VS Code extension, the tab shows a notice directing you to Ptah desktop.

The Library includes user-layer copies of shipped skills, agents, and commands. Open an item to read or edit its body and view its history. When an upstream copy changes, a diverged item can be rebased onto the upstream version or kept as your version.

When the action is available, you can request a manual enhancement. Review its preview before applying it, or discard the proposal. History lets you restore an earlier version.

The tab has separate switches for **Skills** and **Skill telemetry**. The Skills switch uses skillSynthesis.enabled. The telemetry switch uses skills.telemetry.enabled, which is on by default. Telemetry can keep recording skill use while Skills is paused.

**Success** is the share of graded task reviews that passed in the current workspace. If there is no graded review, it shows **No grade**.

See [How it works](/skill-synthesis/how-it-works/) for the Library actions.
