PtahCode is a free, open-source desktop app that runs a team of AI agents on your own machine. This section shows the three steps that every new user does: install the app, open a workspace, and connect an AI provider. You do not need a Ptah account.

## What you need

- Windows (Microsoft Store), macOS on Apple Silicon, or Linux x64.
- A project folder.
- At least one AI provider: a Claude Code or Codex sign-in, an API key for a supported provider, or a local model server such as Ollama or LM Studio.

Start with the [installation guide](/getting-started/installation/).
