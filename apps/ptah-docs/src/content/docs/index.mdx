## Start here

Follow these three pages in order.

<Steps>

1. **[Install PtahCode](/getting-started/installation/)** — install the desktop app on Windows, macOS, or Linux.

2. **[Connect a provider](/getting-started/signing-in/)** — sign in to Claude Code or Codex, or add a key for another supported provider.

3. **[Set up your project](/setup/)** — let Ptah analyze your repository and write an agent team for it.

</Steps>

## What Ptah does

<CardGrid>
  <Card title="Chat with a team of agents" icon="comment-alt">
    One conversation, many specialists. Ptah sends each part of the work to an
    agent and shows the execution tree.
    [Chat →](/chat/)
  </Card>
  <Card title="Remember your project" icon="star">
    Persistent memory with keyword and vector search keeps decisions available
    across sessions.
    [Memory →](/memory/)
  </Card>
  <Card title="Manage your skills" icon="seti:powershell">
    Edit skills, agents, and commands, and review their history.
    [Skills Library →](/skill-synthesis/)
  </Card>
  <Card title="Run work on a schedule" icon="rocket">
    Scheduled jobs run agents for you. Telegram, Discord, and Slack let you
    talk to Ptah from your phone.
    [Automation →](/automation/)
  </Card>
</CardGrid>

## Good to know

- **Every local capability is free.** Ptah is open source. No account, license key, or credit card is necessary.
- **Your keys stay on your machine.** Credentials go from your machine directly to the AI provider. See [Providers](/providers/).
