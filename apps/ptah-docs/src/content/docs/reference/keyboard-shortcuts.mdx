## App menu

| Action               | Windows / Linux | macOS          |
| -------------------- | --------------- | -------------- |
| New chat             | `Ctrl+N`        | `Cmd+N`        |
| Open folder          | `Ctrl+O`        | `Cmd+O`        |
| Open Settings        | `Ctrl+,`        | `Cmd+,`        |
| Toggle DevTools      | `Ctrl+Shift+I`  | `Cmd+Option+I` |
| Reload window        | `Ctrl+R`        | `Cmd+R`        |
| Quit                 | —               | `Cmd+Q`        |

## Chat input

| Action         | Key           |
| -------------- | ------------- |
| Send message   | `Enter`       |
| Insert newline | `Shift+Enter` |

## Edit

The **Edit** menu has the standard shortcuts of your OS for undo, redo, cut, copy, paste, and select all.
