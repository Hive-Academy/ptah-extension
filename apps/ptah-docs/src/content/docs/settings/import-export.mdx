You can export your Ptah settings to one JSON file and import the file on another machine.

## Export

1. Open **Settings → Advanced**.
2. In the **Membership & data** card, click **Export**.
3. Select where to save the file. The default name is `ptah-settings-export.json`.

The file contains your settings and your secrets: provider API keys, tokens, and the membership key. Ptah shows how many secrets it exported.

<Aside type="caution">
The export file contains your secrets in a readable form. Keep it private. Do not commit it or share it. Delete it after you import it.
</Aside>

## Import

1. Open **Settings → Advanced**.
2. In the **Membership & data** card, click **Import**.
3. Ptah asks **Replace your settings from a file?** Click **Import settings**.
4. Select the export file.

Import replaces your current settings, API keys, and preferences with the contents of the file. If the file contains a membership key, the window reloads.

## Manual backup

To back up agents, skills, plugins, and memory, copy these folders:

| Folder        | Contents                                          |
| ------------- | ------------------------------------------------- |
| `~/.ptah/`    | Settings file, plugins, skills library, database  |
| `~/.claude/`  | User-wide agents and skills                       |

Encrypted secrets are in the Electron user-data folder and work only on the machine that encrypted them. Use **Export** to move secrets.
