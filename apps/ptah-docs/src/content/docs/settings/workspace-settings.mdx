Workspace configuration lives **inside your project**, so you can commit it and share it with your team. Ptah uses two folders:

| Folder     | Purpose                                                       |
| ---------- | ------------------------------------------------------------- |
| `.claude/` | Agents, skills, and Claude settings for the project           |
| `.ptah/`   | Ptah files for the project, such as task specifications and browser screenshots |

## `.claude/` folder

```
.claude/
├── agents/                  # Agents for this project
│   └── reviewer.md
├── skills/                  # Skills for this project
│   └── release-notes/
│       └── SKILL.md
├── settings.json            # Committed Claude settings
└── settings.local.json      # Personal Claude settings, not committed
```

| File / folder         | Purpose                                                   |
| --------------------- | --------------------------------------------------------- |
| `agents/`             | Markdown agents with their own tool permissions           |
| `skills/`             | Skills, each with a `SKILL.md` file                       |
| `settings.json`       | Committed Claude settings, for example `permissions`      |
| `settings.local.json` | Personal Claude settings. Add it to `.gitignore`.         |

The agent reads both settings files when it runs in the workspace.

## `.ptah/` folder

| File / folder  | Purpose                                         |
| -------------- | ----------------------------------------------- |
| `specs/`       | Task specifications for orchestration and the tasks board |
| `screenshots/` | Default output of browser screenshots           |
| `roadmap.md`   | Phased plan from [New project](/setup/new-project/) |

Which plugins and skills are enabled is not stored in the workspace folder. Ptah keeps that in its own workspace state.

## Skill copies for other tools

Ptah can copy skills into folders that other AI tools read, for example `.agents/skills/`, `.github/skills/`, and `.cursor/skills/`. These are derived copies. Ptah adds them to `.gitignore`. See [File locations](/reference/file-locations/#the-harness-user-layer).

## Commit to Git

<Aside type="tip">
Add these entries to `.gitignore`:

```
.claude/settings.local.json
.ptah/screenshots/
```

Commit the agents and skills, so your whole team gets the same setup.

</Aside>

## Create a custom agent

Add a Markdown file to `.claude/agents/` with frontmatter that describes the agent:

```markdown
---
name: reviewer
description: Strict TypeScript code reviewer
tools: Read, Grep, Glob
---

You are a senior TypeScript reviewer...
```

See [Custom agents](/agents/custom-agents/).
