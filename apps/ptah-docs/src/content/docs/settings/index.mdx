Ptah has global settings for your user account and workspace files for each project.

| Layer         | Location                                        | Purpose                                                    |
| ------------- | ----------------------------------------------- | ---------------------------------------------------------- |
| **Global**    | `~/.ptah/settings.json` and the Electron user-data folder | Providers, models, autopilot, memory, MCP port, and other preferences |
| **Workspace** | `<workspace>/.claude/` and `<workspace>/.ptah/` | Agents, skills, Claude settings, and task specifications for the project |

## Open Settings

- Click the **Settings** button on the right of the title bar.
- Or press `Ctrl+,` (Windows and Linux, **File → Settings**) or `Cmd+,` (macOS, **Preferences...**).

![Settings panel](/screenshots/settings-overview.png)

## Settings tabs

| Tab                    | What it holds                                                                                                         |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Providers**          | The main agent, your connections, the **CLI agents** matrix (installed CLIs and Ptah CLI instances), and the background model roles |
| **Context Management** | Subagent prompt-cache TTL, session budget, lane guards, and related context settings                                  |
| **Advanced**           | **Membership & data** (with settings import and export), agent behaviour, output styles, the MCP port, and the advanced setting groups |
| **Search & Voice**     | Web search providers and voice                                                                                        |

The result of a save, a test, or another action shows as a notification in the bottom-right corner of the Settings page. When Ptah knows the previous value, the notification has an **Undo** action.
