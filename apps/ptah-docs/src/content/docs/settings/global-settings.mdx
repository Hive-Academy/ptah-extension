Ptah stores global settings in three places:

| Store                                  | What it holds                                                        |
| -------------------------------------- | -------------------------------------------------------------------- |
| `~/.ptah/settings.json`                | Provider, agent, memory, autopilot, scheduler, and gateway settings  |
| `config.json` in the Electron user-data folder | Other app settings                                           |
| `secrets.json` in the Electron user-data folder | API keys and tokens, each value encrypted                   |

See [File locations](/reference/file-locations/) for the paths on each OS.

## `~/.ptah/settings.json`

Edit settings in the Settings page when you can. You can also edit the file by hand. Ptah watches the file and picks up changes.

The docs name keys in dot notation, for example `autopilot.permissionLevel`. On disk, the file uses nested objects:

```json
{
  "autopilot": {
    "enabled": false,
    "permissionLevel": "ask"
  }
}
```

### Main key groups

| Prefix                 | What it controls                                              | See                                            |
| ---------------------- | ------------------------------------------------------------- | ---------------------------------------------- |
| `provider.*`           | Provider endpoints and model tiers                            | [Providers](/providers/)                       |
| `agentOrchestration.*` | CLI agent models, effort, auto-approve, and disabled CLIs     | [Ptah CLI](/providers/ptah-cli/)               |
| `ptahCliAgents`        | Ptah CLI instances                                            | [Ptah CLI](/providers/ptah-cli/)               |
| `autopilot.*`          | Approval mode                                                 | [Autopilot](/settings/autopilot/)              |
| `memory.*`             | Memory, curator, and lifecycle                                | [Memory](/memory/)                             |
| `skillSynthesis.*`     | Skill synthesis                                               | [Skill synthesis](/skill-synthesis/)           |
| `cron.*`               | Scheduled jobs                                                | [Automation](/automation/)                     |
| `gateway.*`            | Telegram, Discord, and Slack gateways                         | [Automation](/automation/)                     |
| `browser.*`            | Browser automation                                            | [Browser automation](/browser-automation/)     |
| `mcp.externalCallerAccess` | Access of external MCP callers (default `read-only`)      | [MCP](/mcp-and-skills/)                        |

## Encryption of secrets

<Aside type="tip">
Ptah encrypts each secret with Electron `safeStorage`, which uses the OS keychain:

- **Windows** — DPAPI (per user)
- **macOS** — Keychain
- **Linux** — libsecret

</Aside>

If `safeStorage` is not available, for example on Linux without a keyring, Ptah stores secrets as plain text and logs a warning.

## Reset to defaults

To reset the file-based settings, quit Ptah, move `~/.ptah/settings.json` to a backup location, and start Ptah again. Secrets are not in this file.
