Autopilot sets how much an agent can do without a pause for your approval. Autopilot is off by default. Then Ptah asks before each action that needs approval.

## Approval modes

Select the approval mode from the autopilot control in the chat input.

| Mode          | Setting value | Effect                                   |
| ------------- | ------------- | ---------------------------------------- |
| Off (ask)     | `ask`         | Ptah asks before actions.                |
| **Auto-edit** | `auto-edit`   | File edits are approved without a prompt. |
| **Plan Mode** | `plan`        | Read-only analysis. The agent makes no changes. |
| **Full Auto** | `yolo`        | All actions are approved without a prompt. |

In every mode, questions from the agent still come to you.

<Aside type="caution">
**Full Auto** lets agents run any command on your machine. Use it only in environments that you can discard, or when you fully trust the agent configuration.
</Aside>

## Settings keys

Ptah stores autopilot in `~/.ptah/settings.json` as `autopilot.enabled` (default `false`) and `autopilot.permissionLevel` (default `ask`):

```json
{
  "autopilot": {
    "enabled": false,
    "permissionLevel": "ask"
  }
}
```

## Workspace permission rules

The agent also reads the Claude settings files of the workspace: `.claude/settings.json` and `.claude/settings.local.json`. Use a `permissions` block there to allow or deny tools for the project:

```json
{
  "permissions": {
    "allow": ["Read", "Grep", "Glob"],
    "deny": ["Bash(rm:*)"]
  }
}
```

See [Autopilot in chat](/chat/autopilot/) for the use in a session.
