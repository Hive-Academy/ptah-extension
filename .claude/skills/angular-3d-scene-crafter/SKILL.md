# Angular 3D Scene Crafter

## Rules

- Before generating scene code, check the project's `package.json` for `@hive-academy/angular-3d`; install it or confirm the intended version if absent.
- For a reference image, map observed color, lighting, material, geometry, depth, and effects to components before building the scene.
- For a written brief, choose a scene composition and build camera, objects, materials, lights, motion, and effects incrementally before presenting the complete Angular component.
- Use existing scene assets as opt-in starting drafts; adapt their documented values to the user's design.
